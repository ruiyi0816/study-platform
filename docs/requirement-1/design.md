## 1. 方案总览

### 1.1 一句话方案

以知识点（kp_id）为主键，把“选章节 → 看知识点/微课 → 做题 → 即时判分 → 错题入本 → 变式重做 → 掌握度回写 → 报告反馈”压缩为手机竖屏上的短路径，并用**最小内容后台**保证内容可供给、**统一埋点看板**保证效果可度量。

### 1.2 MVP 方案骨架

| 层次 | MVP 方案内容 | 设计载体 |
|---|---|---|
| 用户层 | 学生端 Web；小学 1–6、初中 7–9 语数英；统编/人教/沪教牛津；全免费 | P-01～P-08 |
| 学习层 | 首页学习中心、教材五级选择、章节学习、同步练、错题本、学情报告、个人中心 | P-02～P-08 |
| 内容层 | 教材树、章节-KP 映射、题库（答案/解析/难度/来源/版权/城市）、微课/例题 | P-04、P-09 |
| 规则层 | 客观题判分、提交幂等、错题去重与掌握、掌握度/时长口径、城市与版本切换、免费边界 | 第 6、7 节 |
| 支撑层 | 手机号+微信 H5 登录、监护人同意、账号注销、内容审核发布、埋点看板、客服入口 | P-01、P-08～P-11 |
| 非目标 | 原生 App、直播课、B 端学校版、独立家长端、AI 答疑、打卡、物理化学、高中、北师大版、广告 | 1.6 |

### 1.4 设计原则

1. **任务优先**：首页只回答“今天练什么”，主区块不超过 3 个（今日任务/继续学习、薄弱点），报告仅作入口，不放资讯、广告、排行。
2. **一屏一主行动**：章节页主行动是“开始练习”；练习页主行动是“下一题/提交”；结果页主行动是“看错题/再练一组”。
3. **进度不丢**：教材版本、城市、设备、年级变化都不得删除已完成进度；未提交草稿独立保存。
4. **不比较、不诱导**：只呈现个人数据；不做班级/地区排名、分享解锁、连续登录强迫、练习中付费弹窗。
5. **口径透明**：任何百分比、时长、薄弱点都能下钻到证据（题目、作答、时间），并附“如何计算”。
6. **失败可恢复**：所有网络与判分失败都有明确状态、重试入口与兜底文案；不静默失败、不伪造成功。

### 1.5 关键设计取舍

| 取舍点 | 选择 | 理由 | 代价/风险 | 关联 |
|---|---|---|---|---|
| 练习结果是否独立成页 | 结果作为练习页的“结果态”，不新增一级页面 | 减少一次跳转与返回栈复杂度；交卷后原地看解析 | 练习页状态增多，需严格区分作答态/判分中/结果态 | DS-05 |
| 移动端导航 | 4 个底部 Tab（首页/教材/错题本/我的），报告从首页卡片、结果页、我的进入 | 聚焦“练—错—报”核心；Tab 不拥挤 | 报告曝光降低 | DS-02 |
| 城市选择 | 首次教材引导中可选择“暂不选择（通用）”，不阻断 | 降低首练门槛；符合 R-10 不以定位阻断 | 城市卷匹配度下降（V1） | DS-03 |
| 练习难度 | MVP 只出基础难度；分层入口不展示 | 与 P1 范围一致，避免空入口 | 学有余力学生缺少挑战 | A-05、F-07 |
| 未作答题目 | 不计分、不计入掌握度、不自动入错题本，结果页单独标识 | 避免把“没来得及做”误判为“不会” | 得分口径需向学生说明 | DS-06 |
| 判分等待 | 不用前端估算分数，统一“判分中”状态，失败可重试 | 保证结果与解析一致，避免假分数 | 弱网下等待感更强 | AC-03-3/7 |
| 主观题 | 只展示参考答案与自评清单，明确标识“不计入自动判分” | 不伪装自动判分，控制 MVP 范围 | 可用样本减少 | A-05、AC-03-11 |
| 小学 1–2 年级 | 不做儿童版；在登录/选教材处提示家长协助，交互保持大触控目标 | 控制范围；仍保证可用 | 低年级独立完成率有限 | A-09 |

### 2.5 场景边界与设计约束

| 维度 | 需求边界 | 设计含义 |
|---|---|---|
| 终端 | 手机浏览器为主，兼容桌面；微信内 H5 可用；不做 App | 移动优先设计；桌面为放大版布局，不另做一套交互 |
| 网络 | 4G/5G/WiFi；容忍 3G/弱网、短时断网、切后台 | 关键页有骨架屏、重试、离线提示；答案本地缓存 |
| 时间 | 课后 16:00–21:00 高峰；异步 | 不设计实时课堂/直播；判分与报告允许短时延迟（5 分钟内） |
| 地点 | 家庭为主，不依赖校园网 | 不假设校内统一身份/网络 |
| 账号 | 一学生一账号；MVP 无独立家长账号 | 家长能力 V1 以 H5 + 手机号验证承接 |
| 监护 | 未满 14 周岁需监护人同意；1–2 年级家长协助 | 注册流程内置同意门禁；低年级文案与操作简化 |
| 设备 | 320–430 CSS px 竖屏为主 | 320 宽可用；触控 ≥44×44；安全区适配 |
| 内容 | 仅 6 学科组、3 版本；其他明确“敬请期待” | 未开放入口禁用/隐藏；不出现死链 |

### 2.6 关键设计约束（来自场景）

1. **低年级协助模式**：1–2 年级不单独做儿童版，但登录页、教材选择页提供“家长协助”提示；不采集真实姓名/学校/班级。
2. **不排名**：任何页面不得出现班级、学校、地区、全国排名或“超过 X% 同学”。
3. **不诱导**：练习中不出现付费弹窗、分享解锁、连续登录奖励；MVP 无任何付费入口。
4. **可中断**：任何时刻退出练习都不丢已作答内容（本地 + 服务端草稿）。
5. **可解释**：掌握度、时长、薄弱点、推荐理由四处必须能说明口径或来源。
6. **弱网优先**：题干与选项优先渲染，图片/微课延迟加载；判分失败可重试且不重复计分。

### 3.4 “三步进入练习”规则

**计数定义**：从首页（`/`）起算，到“第 1 题可作答”的一次页面跳转或按钮点击计 1 次；Tab 切换计 1 次；页面内滚动、展开解析、切换选项不计。首次配置（登录、监护人同意、城市、教材选择）在完成后不再重复计数。

| 起点/状态 | 路径 | 点击数 | 结论 |
|---|---|---|---|
| 首页，有未提交草稿 | 首页“继续学习” → 练习页恢复 | 1 | 达标 |
| 首页，无草稿，有上次章节 | 首页“今日任务” → 章节页 → “开始练习” | 2 | 达标 |
| 教材 Tab，已选教材 | 教材 Tab → 章 → “开始练习” | 3 | 达标（边界） |
| 教材 Tab，未选版本 | 教材 Tab → 版本 → 册 → 章 → 开始练习 | 4+ | 仅首次配置；配置完成后必须回到 ≤3 |
| 结果态，想再练一组 | 结果态“再练一组” → 新 attempt | 1 | 达标 |

**例外与约束**：

1. 未登录访问深链时，登录后必须回到原目标；登录本身不计入三步。
2. 新用户首次配置以“完成一次练习”为目标，允许超过 3 步，但需满足 3.5 的引导约束。
3. 任何页面不得用“再点一次确认”人为增加步骤（提交确认、退出确认除外）。

### 3.5 深链、登录回跳与返回规则

| 规则 | 设计要求 |
|---|---|
| 受保护页面未登录 | 跳转 `/login?redirect=<编码后的原路径+查询>`；登录成功后回跳，不落到首页；新用户先完成年级/教材最小配置，再回跳原目标，配置过程不丢 `redirect` |
| 微信授权失败/拒绝 | 停留登录页并提示，可回退手机号登录；`redirect` 参数保留 |
| 登录态过期 | 静默续期失败时，保存当前作答草稿后再跳登录；回跳后恢复 |
| 返回 | 二级页返回上一级；练习结果态返回章节页；错题详情返回列表并保留筛选条件 |
| 刷新 | 练习页刷新后从草稿恢复；结果态刷新仍展示结果（按 attempt 查询） |
| 已交卷 attempt | 再次打开进入结果态，不可修改答案 |
| 不存在/已下线内容 | 404/友好提示 + “返回教材”/“去练习”，不白屏 |
| 越权访问 | 403 提示“无权查看该内容”，不泄露资源是否存在 |

**移动端（320–767）**

**全局约束**：

- 正文 ≥16px；行高 1.6；最小可点击 44×44；主按钮高度 48px。

- 网络状态：离线时顶部提示条“网络不可用，已保存本地进度”，恢复后自动重试。

## 4. 核心用户旅程

> 说明：以下旅程描述“设计上应当发生什么”，不是已执行的测试记录。每条旅程末尾的“成功判据”是待执行检查条件，对应第 10 节 DA 与需求基线 AC/UAT。

### 4.1 J-01 新用户首次练习

**目标**：新用户在手机竖屏上完成“登录 → 配置 → 首次练习 → 看解析 → 错题入本”，不迷路、不被合规流程劝退。
**前置**：未登录；微信内或手机浏览器；网络可用。
**关联**：F-01、F-02、F-03、F-18、F-19；UAT-01、UAT-02、UAT-09。

| # | 页面 | 用户动作 | 系统响应 | 数据/状态 | 异常分支 |
|---|---|---|---|---|---|
| 1 | 落地页/首页 | 打开分享链接或直接访问 | 未登录展示产品一句话 + “登录/注册”；不展示任何个人数据 | 记录来源渠道 | 链接失效 → 404 + 回首页 |
| 2 | P-01 | 选择手机号或微信登录 | 手机号发 6 位验证码（5 分钟有效、60 秒重发）；微信内拉起公众号网页授权；**此步仅完成身份验证，不创建账号** | 仅会话暂存，不落库 | 验证码错误 5 次锁定 10 分钟；微信拒绝 → 提示并回退手机号 |
| 3 | P-01 | 阅读并勾选协议 | 用户协议、隐私政策、未成年人规则可打开；默认不勾选 | 协议版本与时间随账号创建落库 | 未勾选不能继续；拒绝则不收集个人信息 |
| 4 | P-01 | 选择年龄段/是否未满 14 周岁 | 未满 14 周岁进入监护人同意页；监护人手机号验证 + 独立勾选；**同意后才创建/登录账号** | 创建 user；未满 14 另记 guardian_consent | 监护人拒绝 → 终止注册，清除会话暂存，不落库学生信息 |
| 5 | P-01 | 设置年级（1–9） | 必选；1–2 年级提示“建议家长协助完成设置” | student_profile.grade | 不选不能继续 |
| 6 | P-03 | 选择城市（可“暂不选择”） | 广州/深圳/暂不选择；暂不选择 = generic | student_profile.city | 不阻断；后续可改 |
| 7 | P-03 | 学段→学科→版本→册→章 | 默认当前学期；已开放节点可选，未开放禁用并说明 | 保存教材偏好与章节 | 内容准备中 → 说明 + 返回 |
| 8 | P-02 | 查看新用户引导 | 引导卡“开始第一次练习”，指向当前章节；不展示薄弱点（无数据） | 引导状态 | 章节无题 → 推荐同册已开放章节 |
| 9 | P-04 | 看知识点清单，点“开始练习” | 展示 KP、微课（可选）、例题；微课失败不阻断 | 创建 attempt（基础难度、默认题量） | 题库不足 → “本章节题目准备中” |
| 10 | P-05 | 逐题作答并提交 | 本地即时保存；提交二次确认未答题目；判分中 → 结果态 | attempt→graded；attempt_item 快照 | 断网/提交失败 → 本地保留，可重试 |
| 11 | P-05 结果态 | 查看得分与逐题解析 | 展示正确答案、解析、KP；错题自动入本 | wrong_book 新增；mastery 待更新 | 解析缺失 → 该题不应发布；线上异常则该题下线并提示 |
| 12 | P-06/P-02 | 去错题本或回首页 | 错题本出现该题；首页“继续学习”更新 | 埋点 wrong_add、report 待刷新 | 报告 5 分钟内更新；未完成显示“更新中” |

**成功判据（待执行）**

1. 全流程无阻断，手机竖屏可完成；从登录到看到解析不需要桌面端介入。
2. 协议非默认勾选；未满 14 周岁未同意时无法完成注册。
3. 首次练习提交后 1 秒内（P95）看到结果；错题本出现该错题。
4. 微信拒绝授权可回退手机号，且登录后回到原目标章节。

**设计要点**

- 新用户配置常规压缩为“登录/同意 → 年级 → 教材”三屏以内（城市在同屏可选）；未满 14 周岁额外增加监护人同意步骤，不因此减少协议展示。
- 不强制填写昵称、真实姓名、学校、班级；昵称可跳过，默认“同学”。
- 首次进入首页不展示“薄弱点/报告”空图表，改为“完成 1 次练习后解锁学情报告”的引导卡。
- 若教材内容未就绪，明确说明“内容准备中”并给同册可练章节，不把用户留在死胡同。

### 4.2 J-02 日常同步练

**目标**：已配置学生用最少步骤完成当天章节练习，并知道下一步练什么。
**前置**：已登录、已选教材与章节；当前学期已识别。
**关联**：F-02、F-03、F-19；UAT-01、UAT-04。

| # | 页面 | 用户动作 | 系统响应 | 数据/状态 |
|---|---|---|---|---|
| 1 | P-02 | 打开首页 | 按优先级生成“今日任务/继续学习”：① 未完成草稿；② 上次练习章节的下一节；③ 当前学期首个已开放章节 | 读取 attempt 草稿、章节进度 |
| 2 | P-02 | 点“今日任务” | 进入章节页；若为草稿则直接恢复练习 | attempt_id |
| 3 | P-04 | 浏览 KP/微课/例题 | 微课可选，默认不自动播放；例题可展开解析 | 学习行为埋点 |
| 4 | P-04 | 点“开始练习” | 创建 attempt；MVP 难度固定基础；显示题量 | attempt.created |
| 5 | P-05 | 作答并提交 | 判分 → 结果态 → 错题入本 → 掌握度回写 | graded |
| 6 | P-05 结果态 | 看解析/再练一组 | “再练一组”创建同章节新 attempt；不重复出已做题优先 | 新 attempt |
| 7 | P-02/P-07 | 回首页/看报告 | 首页薄弱点、报告在 5 分钟内更新 | 更新中状态 |

**今日任务生成规则（设计固化）**

1. 有未提交草稿 → “继续学习”优先展示草稿，显示章节名、已答/总题数、最后保存时间。
2. 无草稿 → 取“上次练习章节”的下一节（按章节树顺序，跳过未开放/无题章节）。
3. 无历史 → 当前学期首个已开放章节。
4. 无任何可推荐章节 → 显示“去选章节”，不显示空白卡片。
5. 推荐只来自当前教材版本与已开放内容；切换版本或城市后立即重算（AC-19-7）。

**成功判据（待执行）**：首页到开始练习 ≤3 次点击；今日任务不推荐未开放内容；结果态可一键再练；错题与报告状态联动。

### 4.3 J-03 练习中断与恢复

**目标**：任何中断都不丢已作答内容；恢复后不重复计分、不重复入错题。
**前置**：练习进行中（attempt=draft）。
**关联**：F-03、F-06；UAT-04、UAT-05。

| 中断类型 | 系统行为 | 恢复路径 | 用户可见反馈 |
|---|---|---|---|
| 切后台/锁屏 | 本地即时保存；`pagehide` 时尝试同步服务端 | 回前台自动恢复当前题与答案 | 顶部轻提示“已保存” |
| 断网 | 本地保存；提交失败进入“待重试” | 网络恢复后自动重试或手动重试 | “网络不可用，答案已保存在本机” |
| 来电/系统中断 | 同切后台 | 回前台恢复 | 不弹阻断弹窗 |
| 刷新/关闭浏览器 | 服务端草稿（最近一次同步） | 首页“继续学习”或深链恢复 | 展示“已恢复上次作答” |
| 换设备 | 服务端草稿 | 另一设备打开同一 attempt | 提示“已同步其他设备的最新草稿” |
| 草稿超过 24 小时 | 标记过期，不可恢复 | 提示“草稿已过期，请重新开始” | 提供“重新开始”按钮 |
| 多端同时提交 | 先提交者生效；后提交返回已交卷 | 后提交端进入结果态 | “该练习已在其他设备提交” |

**草稿保存设计（DS-04）**

- 触发：每次选择/输入后本地立即保存；服务端按 2 秒防抖同步；页面隐藏、提交前强制同步。
- 范围：题干版本、已选答案、当前题号、剩余时间（如启用）、最后更新时间。
- 归属：草稿属于“学生 + attempt”，不因切换教材版本/城市而删除；切换只影响首页推荐。
- 冲突：同一 attempt 服务端仅保留一份草稿，后写入覆盖先写入；恢复时展示最后更新时间，避免用户误以为丢失。
- 过期：自最后保存起 24 小时（建议值，可配置）过期；过期后不静默删除页面内内容，提交前提示重新开始。
- 安全：草稿仅本人可读写；退出登录清除本地草稿缓存，服务端草稿保留至过期或提交。

**提交幂等设计**：见 6.1 与 7.3。

**成功判据（待执行）**：断网/切后台/来电/刷新后答案不丢；重复点击与多端提交只产生一次有效结果；草稿过期提示明确。

### 4.4 J-04 错题复盘

**目标**：学生能找到错题、看懂错因、做变式、看到“已掌握”的变化。
**前置**：错题本已有记录。
**关联**：F-04、F-05；UAT-06。

| # | 页面 | 用户动作 | 系统响应 | 数据/状态 |
|---|---|---|---|---|
| 1 | P-06 | 进入错题本 | 默认“待复习”，按最近错误时间倒序；显示总数与按 KP 聚类入口 | wrong_book |
| 2 | P-06 | 筛选学科/章节/KP/错因/状态/时间 | 列表即时刷新；保留筛选条件 | 查询条件 |
| 3 | P-06 详情 | 打开错题 | 展示原题快照、我的答案、正确答案、解析、KP、错误次数、来源 | 快照版本 |
| 4 | P-06 详情 | 选择错因（可跳过） | 三选一：概念不清/计算失误/审题偏差；可改；不影响判分 | wrong_book.cause |
| 5 | P-06 详情 | 点“重做” | 内联作答卡；提交即时判分 | 重做 attempt（单题） |
| 6 | P-06 详情 | 点“变式题” | 同 KP → 同题型 → 难度 ±1 → 未做优先 | 变式题 |
| 7 | P-06 详情 | 重做正确 | 显示“连续正确 1/2（需间隔 ≥1 个自然日）”；满足 2 次后标记已掌握 | mastery/wrong status |
| 8 | P-06 | 查看“已掌握” | 已掌握列表保留历史，可手动恢复为待复习 | 状态回退 |
| 9 | P-06 详情 | 删除错题 | 二次确认；软删除；报告口径同步 | deleted |

**异常与兜底**

| 情况 | 设计处理 |
|---|---|
| 无变式题 | 明确提示“暂无变式题”，给“练同知识点题目”入口；不返回空列表、不重复原题 |
| 变式题也做过 | 优先未做；全部做过则允许重复但标注“已做过”，并给同 KP 其他题 |
| 原题已下线 | 可看历史快照；重做/变式按钮禁用并说明 |
| 错题为空 | 引导“去练习/去选章节”，不出现空白页 |
| 错题量大（如 500 条） | 分页/加载更多；默认按 KP 折叠；列表滚动性能可接受 |
| 越权访问他人错题 | 403，不泄露是否存在 |

**成功判据（待执行）**：错题可被找到、可重做、状态可从“待复习”变为“已掌握”并可恢复；报告薄弱点与错题本一致（AC-04-*、AC-05-*）。

### 4.5 J-05 报告查看与下钻

**目标**：学生看懂“我哪里弱、花了多久、有没有进步”，并能下钻到证据；V1 家长通过周报查看摘要。
**前置**：有作答数据（至少 1 次提交）。
**关联**：F-05、F-19；UAT-06、UAT-08。

| # | 页面 | 用户动作 | 系统响应 | 数据/状态 |
|---|---|---|---|---|
| 1 | P-02/P-05/P-08 | 点“学情报告” | 默认本周（UTC+8 自然周）；无数据给引导 | report |
| 2 | P-07 | 查看总览 | 整体掌握度、本周时长、薄弱点 Top 5、近 4 周趋势 | 聚合 |
| 3 | P-07 | 切换学科/章节 | 展示对应范围掌握度与样本量 | 聚合 |
| 4 | P-07 | 点薄弱点 | 下钻到该 KP 的错题/题目列表 | 下钻 |
| 5 | P-07 | 点章节 | 下钻到章节练习记录（attempt 列表） | 下钻 |
| 6 | P-07 | 点“如何计算” | 说明掌握度窗口、权重、样本要求、时长口径、时区 | 口径页 |
| 7 | P-07 | 数据未更新 | 显示“更新中，预计 5 分钟内”，不显示旧数据为新数据 | 状态 |

**成功判据（待执行）**：掌握度符合 R-08 与 7.5 算例；样本 <3 显示“数据不足”；周时长按自然周与活跃口径；报告不含排名；薄弱点与错题本一致；可下钻。

### 4.6 J-06 教材版本、城市与年级变更

**目标**：换版本/城市/年级不丢进度、不混淆数据、不产生错误推荐。
**关联**：F-02、F-15；UAT-03。

| 变更 | 入口 | 交互 | 数据影响 | 明确提示 |
|---|---|---|---|---|
| 教材版本 | P-03 顶部版本切换、P-08 学习设置 | 选择新版本 → 确认 → 定位到同年级同学期册 | 原版本进度独立保留；KP 掌握度跨版本聚合 | “切换不会删除原版本进度” |
| 城市 | P-03 首次选择、P-08 | 广州/深圳/暂不选择 | 只影响推荐与 V1 城市卷；不改历史掌握度 | “城市仅用于内容推荐” |
| 年级 | P-08 | 选择新年级 → 确认 | 默认展示新年级当前学期；旧年级进度保留 | “历史进度不会删除” |
| 学期 | 自动 | 按 UTC+8 日期默认上/下册（9/1–1/31 上册，2/1–8/31 下册） | 可手动切换 | 运营可按校历配置覆盖 |

**边界**：切换版本时若有未提交草稿，提示“草稿已保存，可稍后继续”，不强制阻断；返回原版本时恢复上次章节与草稿入口（AC-02-3）。

### 4.7 J-07 账号权利与注销

**目标**：学生/家长能查询、更正、注销账号，且流程可审计。
**关联**：F-01、F-15、F-18；UAT-09、UAT-10。

| # | 页面 | 用户动作 | 系统响应 | 异常 |
|---|---|---|---|---|
| 1 | P-08 | 进入“账号与安全” | 展示脱敏手机号、微信绑定状态、注销入口 | — |
| 2 | P-08 | 点“注销账号” | 展示影响：学习记录/错题/报告删除或匿名化、订单/订阅处理、不可恢复 | 有未完成订单/订阅 → 给处理指引，不静默失败 |
| 3 | P-08 | 短信验证 | 向当前手机号发验证码 | 验证失败可重试，限流 |
| 4 | P-08 | 二次确认 | 勾选“我已了解” → 确认注销 | 网络失败可重试，不重复提交 |

**成功判据（待执行）**：注销入口 ≤3 次点击；注销前告知影响；注销后无法登录、手机号可重注册、无可识别信息残留；客服可受理查询/更正（AC-15-*）。

### 4.8 J-08 教研内容上架（内部）

**目标**：教研不依赖研发完成章节/知识点/题目/解析的上架、审核、发布与回滚。
**关联**：F-16；UAT-12。

| # | 页面 | 角色 | 动作 | 系统校验/结果 |
|---|---|---|---|---|
| 1 | P-09 | 教研编辑 | 新建/导入教材版本、册、章节树 | 层级、排序、状态校验 |
| 2 | P-09 | 教研编辑 | 关联 KP（支持批量） | 章节至少 1 个 KP 才能发布练习 |
| 3 | P-09 | 教研编辑 | 录入题目：题干、题型、选项、答案、解析、KP、难度、来源、版权状态 | 必填缺失不能提交审核 |
| 4 | P-09 | 教研编辑 | 提交审核 | 生成审核任务 |
| 5 | P-09 | 教研审核 | 通过/驳回 | 编辑与审核权限分离 |
| 6 | P-09 | 教研审核 | 发布 | 发布前自动校验；1 分钟内学生端可见（建议值） |
| 7 | P-09 | 教研审核 | 下线/回滚 | 学生端不可见；历史作答不受影响 |
| 8 | P-09 | 管理员 | 查看操作日志 | 操作人、时间、对象、前后值可检索 |

**内容门禁（设计侧，具体数值待 Q-07/A-14 确认）**

- 章节发布：≥1 个 KP 映射；至少 1 道可判分题；解析 100%；未开放章节不得出现在学生端推荐。
- 题目发布：题干、答案、解析、≥1 主 KP、难度、题型、来源、版权状态、审核人齐全；缺一不可。
- 建议内容基线（A-14，待确认）：每上线章节 ≥10 题（基础 5/提升 3/挑战 2）、每 KP ≥3 题、微课覆盖 ≥80% 核心章节。
- 题目修订：生成新版本；历史作答保留快照；不回溯改变报告。

### 4.9 J-09 家长周报与订阅（V1 方向，不做 MVP 验收）

**目标**：家长在微信内查看周报并完成订阅，学生端权益即时生效；不新增独立家长 App。
**关联**：F-14a、F-05；A-03、Q-05、Q-13。

**设计方向**

1. 绑定：学生账号生成绑定入口 → 家长手机号验证 → 绑定关系；一个学生可绑定家长手机号（数量与验证方式待 Q-05/Q-13 确认）。
2. 周报：本周时长、练习次数、掌握度变化、薄弱点；只读；不含排名；不向学生公开支付信息。
3. 订阅：方案/价格/权益/退款规则明示；监护人确认；自动续费默认关闭；支付后权益即时生效。
4. 状态：待支付/支付中/已支付/支付失败/已退款/已过期；重复支付可识别并退款。
5. 过期：学生数据保留，只读或降级，不删除错题与进度。

> 本节只用于说明 V1 的承接方式，**不进入 MVP 设计验收**；MVP 不出现任何付费入口、价格或支付采集。

## 5. 页面级设计方案

> 每页包含：目标、信息结构、关键交互、状态设计、文案要点、埋点、验收要点。ASCII 为结构示意，不是视觉稿。

### 5.1 P-01 登录/注册

**目标**：低门槛进入；微信内一键授权；合规同意可审计；失败可回退。

**信息结构（移动端）**

```
[产品名 + 一句话]
[微信一键登录]（仅微信内置浏览器展示）
[手机号输入] [获取验证码] [登录/注册]
[ ] 我已阅读并同意《用户协议》《隐私政策》《未成年人保护规则》
[首次注册] 年龄确认 →（未满 14 周岁）监护人同意
[家长协助提示]（1–2 年级文案）
[帮助与反馈]
```

**关键交互**

1. 手机号：11 位数字键盘；实时格式校验；验证码 6 位、5 分钟有效、60 秒重发；连续错误 5 次锁定 10 分钟（建议值）。
2. 微信：仅在微信内置浏览器展示；拉起公众号网页授权；拒绝/回调失败 → 提示 + 回退手机号，不阻断。
3. 协议：默认不勾选；未勾选点击登录 → 高亮协议行并提示；协议在登录前可打开。
4. 年龄/监护（首次注册，在创建账号前）：先问“是否未满 14 周岁”；未满 → 监护人须知 + 监护人手机号验证 + 独立勾选；拒绝则终止，不创建账号、不落库学生信息（仅会话暂存）（DS-08）。
5. 登录成功：按 `redirect` 回跳；无 `redirect` → 首页；新用户 → 年级/教材引导（带 `redirect` 时，完成最小配置后回跳原目标）。
6. 错误提示不泄露“手机号是否已注册”；验证码接口限流；`redirect` 仅接受站内相对路径，防开放重定向。

**状态设计**

| 状态 | 表现 | 操作 |
|---|---|---|
| 初始 | 表单可用，协议未勾选 | 输入/微信登录 |
| 发送中 | 按钮倒计时，防重复 | 等待 |
| 验证失败 | 行内错误“验证码不正确或已过期” | 重试/重发 |
| 锁定 | 提示剩余时间；按钮禁用 | 等待或联系客服 |
| 微信授权中 | 全屏 loading，可取消 | 取消回退 |
| 微信拒绝 | 提示“未获得微信授权，可使用手机号登录” | 回退手机号 |
| 监护人拒绝 | 说明无法完成注册，不保存个人信息 | 返回 |
| 网络异常 | 保留输入，提示重试 | 重试 |

**验收要点**：AC-01-1～8、AC-18-1～3、DA-03、DA-18。

### 5.5 P-05 练习（作答态 / 判分中 / 结果态）

**目标**：手机竖屏单手完成答题；提交后 1 秒内看到判分与解析；中断不丢、不重复计分。

#### 5.5.1 作答态

```
┌──────────────────────────────┐
│ × 退出      3/10   [答题卡]   │
│ 进度条 ██████░░░░             │
│ ┌──────────────────────────┐ │
│ │ 题干（可含图片/公式）      │ │
│ │ A. …  B. …  C. …  D. …   │ │
│ └──────────────────────────┘ │
│ [上一题]        [下一题/提交] │
│ 已自动保存                    │
└──────────────────────────────┘
```

**交互规则**

| 项 | 规则 |
|---|---|
| 单选 | 点击选项即选中；可改选；不提供“取消选择”防误清 |
| 多选 | 点击切换；未选任何项视为未作答（提交时单独标识，不强制选择） |
| 判断 | 两个大按钮“正确/错误” |
| 填空 | 数字/文字键盘按题型切换；去首尾空格；支持全半角/大小写归一（判分侧） |
| 答题卡 | 网格题号；已答/未答/当前三态；点击跳转；长练习可滚动 |
| 上一题/下一题 | 不强制作答；最后一题按钮变“提交” |
| 提交 | 全部答完 → 直接提交（按钮防抖）；有未答 → 二次确认列出题号，可选“继续作答/仍要提交” |
| 退出 | 二次确认“退出后已答内容保存为草稿”；确认后回章节页 |
| 自动保存 | 每次作答本地保存；顶部/底部显示“已保存/保存中/保存失败” |
| 防作弊 | MVP 不做监考/切屏检测；不采集与学习无关的设备信息 |

**题量与时长**：MVP 默认 10 题/次（建议值，后台可按章节配置；需求基线建议单次 10–15 题、10–15 分钟）。题量不因设备或网络变化；题库不足时整次练习不生成，不临时拼凑。

#### 5.5.2 判分中

- 提交后立即进入全屏/半屏“判分中”，显示进度动效与“正在判分，请稍候”。
- **不显示估算分数**；不显示对错；禁止重复提交。
- 目标 P95 ≤1 秒；超过 3 秒显示“仍在判分，可稍后查看”；超过 10 秒显示“重试/返回首页（结果保留）”。
- 判分失败：保留答案，显示“判分失败，请重试”；重试幂等，不重复入错题。
- 若服务端已接受但客户端超时：重试按 attempt_id 查询结果，不新建 attempt。

#### 5.5.3 结果态

```
┌──────────────────────────────┐
│ 得分 80       正确 8/10  用时 9:12 │
│ [全部] [错题 2] [未作答 0]     │
│ ┌ 1. 对 ───────────────────┐ │
│ │ 题干摘要        [展开解析] │ │
│ └──────────────────────────┘ │
│ ┌ 3. 错 ───────────────────┐ │
│ │ 我的答案 B  正确答案 C     │ │
│ │ 解析：……  知识点：×××     │ │
│ └──────────────────────────┘ │
│ [再练一组] [去错题本] [看报告] │
└──────────────────────────────┘
```

**结果规则**

- 得分：每题等权，正确题数 ÷ 总题数 ×100，四舍五入取整（DS-01，待教研确认）；未作答计 0 分、不计入掌握度、不入错题本。
- 逐题：题干、我的答案、正确答案、解析、KP；默认折叠解析，点击展开；支持“全部展开/收起”。
- 主观题（如启用）：标识“参考解析/自评”，不计入自动判分与掌握度；提供自评清单，不伪装自动判分。
- 错题：自动入本；结果态可一键去错题本；不弹出付费/分享。
- 再练一组：同章节新 attempt；优先未做题目；题量按后台配置；不重复原 attempt。
- 已交卷：不可改答案；刷新/再次进入仍为结果态。

**状态设计**：判分中；判分失败；部分题目解析异常（该题下线提示）；网络中断（结果可稍后查看）；已交卷（只读）。

**验收要点**：AC-03-1～11、AC-06-*、UAT-04/05、DA-06～09、DA-23。

### 5.6 P-06 错题本

**目标**：错题可找到、可看懂、可重做、可看到掌握变化。

**列表**

```
[待复习 12] [已掌握 5] [全部 17]
[筛选：学科 ▾ 章节 ▾ 知识点 ▾ 错因 ▾ 时间 ▾]
[按知识点聚类 ▾]
▾ 分数乘法（4）
   · 题目摘要  错 2 次  最近 11-20  [>]
▾ 应用题（3）
   ...
[加载更多]
```

**列表规则**

1. 默认“待复习”，按最近错误时间倒序；支持按 KP 聚类/按时间两种视图。
2. 筛选：学科、章节、KP、错因、掌握状态、时间；筛选条件在详情返回后保留。
3. 同题去重：一条记录累计错误次数、首次/最近错误时间、来源练习。
4. 空态：引导“去练习/去选章节”；不出现空白页。
5. 大量数据：分页 20 条/页；聚类默认折叠；滚动性能可接受。
6. 越权：仅本人可见；403 不泄露存在性。
7. 跨设备：手机/桌面同一账号看到一致的错题、错因、掌握状态与删除结果；服务端为准。

**详情**

```
[原题快照]  [已下线提示（如适用）]
我的答案：B   正确答案：C   错误 2 次
解析：……
知识点：分数乘法
错因：[概念不清] [计算失误] [审题偏差]（可跳过）
掌握进度：连续正确 1/2（需间隔 ≥1 个自然日）
[重做本题] [变式题] [删除]
```

**详情规则**

1. 原题按作答时快照展示；题目修订不改变历史错题展示。
2. 错因三选一、可跳过、可修改；不影响判分。
3. 重做：内联作答卡（复用判分组件），提交即时判分；不跳转完整练习页。
4. 变式：同 KP → 同题型 → 难度 ±1 → 未做优先；无题给同 KP 题入口；不重复原题/空列表。
5. 掌握：连续 2 次正确（不同次练习、间隔 ≥1 个自然日）→ 已掌握；显示 1/2 进度；可手动恢复。
6. 删除：二次确认；软删除；报告口径同步更新；历史统计按 R-06 处理。
7. 已下线题目：只读快照；重做/变式禁用并说明。

**验收要点**：AC-04-1～9、UAT-06、DA-10～12。

### 5.7 P-07 学情报告（学生版）

**目标**：让学生看懂掌握度、时长、薄弱点与趋势，并能下钻证据；口径可解释。

**信息结构**

```
[本周 ▾]   [如何计算]
┌ 整体掌握度 68% ────────────┐
│ 已掌握 3 KP · 待巩固 4 · 薄弱 2 │
└──────────────────────────┘
┌ 本周时长 85 分钟（日均 12）┐
│ 语文 30 · 数学 40 · 英语 15 │
└──────────────────────────┘
[趋势：近 4 周掌握度/时长]
[薄弱点 Top 5]
 1. 分数乘法 62%  样本 8   [去练]
 ...
[分学科/章节/KP 列表]
```

**规则**

1. 周期：默认本周（UTC+8 周一 00:00–周日 23:59:59）；可切上周；趋势展示近 4 周（建议值）。
2. 掌握度：按 7.5 口径；样本 <3 显示“数据不足”，不显示百分比；不参与薄弱点排序。
3. 整体/学科/章节掌握度：按范围内“样本 ≥3 的 KP”以有效作答次数加权平均；无合格 KP → 数据不足（DS-07，待 Q-04）。
4. 薄弱点：先按掌握度升序、再按样本降序；最多 5 个；点击下钻 KP 题目/错题。
5. 时长：本周总时长、日均、分学科；口径见 7.6；注明“仅统计前台活跃”。
6. 下钻：KP → 题目/错题；章节 → 练习记录；返回保留周期与筛选。
7. 无排名、无班级/地区对比、无公开分享。
8. 更新：提交后 5 分钟内更新；未更新显示“更新中”，不把旧数据标成新数据。

**状态设计**

| 状态 | 表现 |
|---|---|
| 无数据 | 引导“完成 1 次练习解锁报告”；不显示 0/NaN/空图表 |
| 样本不足 | “数据不足，还差 N 次作答”；进度提示，不显示误导百分比 |
| 更新中 | 顶部“数据更新中，预计 5 分钟内”；旧数据标注时间 |
| 加载失败 | 错误 + 重试；保留周期选择 |
| 部分图表失败 | 图表占位 + 文案说明；其他模块可用 |
| 跨周边界 | 按 UTC+8 归属；不因设备时区改变已归属周 |

**验收要点**：AC-05-1～8、UAT-06/08、DA-13～15。

### 5.8 P-08 个人中心

**目标**：资料可查可改、学习设置清晰、协议与客服可达、注销可完成。

### 5.9 P-09 内容管理后台（内部）

**目标**：教研无研发介入完成内容上架、审核、发布、回滚、追溯。

**信息架构**

| 模块 | 能力 | 关键约束 |
|---|---|---|
| 内容概览 | 待审/已发布/已下线/缺解析统计 | 按学科/版本/年级筛选 |
| 教材管理 | 版本、册、章节树新增/编辑/排序/下线 | 章节至少 1 KP 才能发布练习 |
| 知识点 | KP 新增/编辑、前置依赖、考纲映射、批量导入 | 映射缺失校验 |
| 题库 | 题目录入/编辑/导入、答案、解析、难度、来源、版权、city | 必填缺失不能提交审核 |
| 审核队列 | 通过/驳回、驳回原因 | 编辑与审核权限分离 |
| 发布记录 | 发布/下线/回滚、版本差异 | 操作日志可检索 |
| 日志 | 操作人、时间、对象、前后值 | 留存与审计 |

**关键交互**

1. 章节树拖拽排序 → 保存 → 校验层级/空节点；发布后 1 分钟内学生端可见（建议值）。
2. 题目编辑器：题型切换显示对应字段；选项至少 2 项；答案必须属于选项；解析必填；KP 至少 1 个主 KP。
3. 批量导入：模板下载 → 上传 → 行级错误报告 → 修正后重试；失败不部分入库（或明确部分成功清单）。
4. 发布校验：答案、解析、KP、难度、来源、版权状态、审核人齐全；不通过给出具体原因与定位。
5. 修订：生成新版本；历史作答不受影响；可查看版本差异；支持回滚。
6. 下线：二次确认 + 原因；学生端不可见；错题历史快照仍可看。
7. 并发编辑：冲突提示，不静默覆盖。

**验收要点**：AC-16-1～8、UAT-12、DA-21。

### 5.10 P-10 埋点与指标看板（内部）

**目标**：指标可复现、可核对、可解释，不依赖人工对数。

**信息结构**

- 顶部筛选：日期（自然周/月）、城市、学段、学科、版本、终端。
- 指标卡：周有效学习学生数、激活率、7 日留存、周学习天数、错题重做正确率提升、付费转化（V1）。

- 内容：章节覆盖率、题目解析完整率、抽检准确率、内容缺口。
- 数据质量：事件量、与服务端抽样核对、异常告警。

**规则**

4. 空数据/延迟显示“数据更新中”，不显示 0 冒充真实值。
5. 北极星不作为 MVP 硬门槛，发布后 4 周建立基线。

**验收要点**：AC-17-1～6、UAT-13、DA-20。

## 6. 核心交互与状态机

> 状态机用于统一前后端、设计与测试对“当前处于什么状态、能做什么、下一步是什么”的理解。状态命名是设计约定，最终字段以实现为准，但状态语义与用户可见行为不得减少。

### 6.1 练习 attempt 状态机

```
                 ┌──────────────┐
   开始练习 ───▶ │    draft     │ ◀── 恢复草稿
                 └──────┬───────┘
                        │ 提交（含未答确认）
                        ▼
                 ┌──────────────┐   失败/超时   ┌────────────────┐
                 │  submitting  │ ───────────▶ │ submit_failed  │
                 └──────┬───────┘ ◀─────────── └────────────────┘
                        │ 服务端接受并判分完成        重试（幂等）
                        ▼
                 ┌──────────────┐
                 │    graded    │  只读：看解析/入错题/再练一组
                 └──────────────┘
draft ──超过 24 小时──▶ expired（不可恢复，需重新开始）
```

| 状态 | 用户可见 | 允许操作 | 禁止操作 | 进入条件 | 离开条件 |
|---|---|---|---|---|---|
| draft | 作答界面；显示已答/总题、保存状态 | 作答、跳题、退出、提交 | 看分数/解析 | 创建 attempt 或恢复草稿 | 提交 / 过期 |
| submitting | “判分中”，不可改答案 | 等待、取消返回（结果保留） | 重复提交、改答案 | 提交请求发出 | 成功 → graded；失败 → submit_failed |
| submit_failed | “判分失败/网络异常”，答案保留 | 重试、退出（保留答案与待重试状态，稍后可恢复） | 改答案（避免与已接受结果冲突） | 提交失败/超时 | 重试成功 → graded；退出 → 保留待重试，可恢复 |
| graded | 得分、逐题解析、错题入口 | 看解析、去错题本、再练一组、看报告 | 修改答案、重复提交 | 判分成功 | 终态（不可逆） |
| expired | “草稿已过期” | 重新开始（新建 attempt） | 恢复旧答案 | 超过 24 小时 | 新建 attempt |

**关键规则**

1. `attempt_id` 在开始练习时生成；提交、查询结果、重试都以它为主键。
2. 提交请求幂等键 = `attempt_id`（同一学生）；服务端只接受一次有效提交，重复请求返回同一结果。
3. 多端同时提交：先被服务端接受者生效；另一端收到“已交卷”，直接进入结果态，不覆盖答案、不重复入错题。
4. 判分失败但服务端已接受：客户端重试只查询结果，不新建 attempt；以服务端结果为准。
5. 已交卷 attempt 不可修改；刷新、换设备、重新登录都进入结果态。
6. 退出登录不删除服务端草稿；本地敏感缓存清除。

### 6.2 草稿生命周期

```
active ──每次作答──▶ saving ──成功──▶ saved
  │                    │失败
  │                    ▼
  │                 save_failed ──重试──▶ saving
  │
  ├── 提交成功 ──▶ submitted（草稿归档，不再恢复）
  └── 最后保存 + 24h ──▶ expired（不可恢复）
```

| 状态 | 判定 | 用户提示 | 处理 |
|---|---|---|---|
| active | 有未提交作答，且未超 24h | “已自动保存” | 正常恢复 |
| saving | 正在同步服务端 | “保存中…” | 防重复；失败降级本地 |
| saved | 服务端已保存 | “已保存 hh:mm” | 可跨端恢复 |
| save_failed | 服务端失败/离线 | “已保存在本机，联网后自动同步” | 本地保留，恢复后重试 |
| submitted | 已交卷 | “已提交” | 不再作为草稿展示 |
| expired | 超过 24h | “草稿已过期，请重新开始” | 不静默删除当前页内容；提交前提示 |

### 6.3 错题状态机

```
       答错首次入本
            │
            ▼
     ┌─────────────┐   连续 2 次正确（不同次练习，间隔 ≥1 自然日）
     │  pending    │ ───────────────────────────────▶ ┌───────────┐
     │ （待复习）   │ ◀─────────────────────────────── │ mastered  │
     └──────┬──────┘        手动恢复为待复习            │（已掌握）  │
            │                                          └─────┬─────┘
            │ 删除（二次确认，软删除）                        │ 删除
            ▼                                                ▼
     ┌─────────────┐                                  ┌───────────┐
     │  deleted    │                                  │  deleted  │
     └─────────────┘                                  └───────────┘

正交标记：question_offline = true → 只读快照，禁止重做/变式（不改变 pending/mastered）
```

| 规则 | 设计定义 |
|---|---|
| 入本 | 首次提交答错即入本；未作答不入本 |
| 去重 | 同一学生同一题目唯一记录；累计错误次数、首次/最近错误时间、来源 |
| 重做正确 | 记录一次“正确”；连续 2 次且满足间隔 → mastered；期间再错则计数清零 |
| 间隔 | 按 UTC+8 自然日计算，两次正确所在日期差 ≥1 天；同一次练习内的多次正确不计数（DS-11） |
| 手动恢复 | mastered → pending；重新计入薄弱点；历史保留 |
| 删除 | 软删除；二次确认；报告口径同步；历史统计按 R-06 建议保留匿名汇总 |
| 题目下线 | 只读快照；入口禁用并说明；不影响历史报告 |

### 6.4 登录与授权状态

```
anonymous ──手机号验证/微信授权──▶ authenticating ──成功──▶ authenticated
    ▲                                   │失败
    │                                   ▼
    └──────────── 退出/注销 ◀──── auth_failed（可重试/回退）
authenticated ──登录态过期──▶ expired ──静默续期失败──▶ anonymous（保存草稿后跳登录）
```

| 状态 | 行为 |
|---|---|
| anonymous | 可看产品介绍；受保护页跳登录并带 redirect |
| authenticating | 按钮 loading，防重复；微信授权可取消 |
| authenticated | 正常访问；登录态建议 7 天（待安全确认，DS-09） |
| auth_failed | 明确原因（验证码错误/授权拒绝/网络），提供回退路径 |
| expired | 先保存草稿，再跳登录；回跳恢复 |
| deleting | 注销处理中；禁止再次发起；完成后退出 |

### 6.5 监护人同意状态

| 状态 | 含义 | 用户可见 | 系统行为 |
|---|---|---|---|
| not_required | 已确认年满 14 周岁 | 正常注册 | 记录声明时间与版本 |
| pending | 未满 14 周岁，等待监护人同意 | 监护人须知 + 验证 + 勾选 | 不保存学生个人信息（仅会话暂存） |
| granted | 监护人已同意 | 继续注册 | 记录关系、时间、协议版本 |
| refused | 监护人拒绝 | 终止注册说明 | 清除暂存；不建立账号 |
| revoked | 后续撤回（按隐私政策） | 客服/流程处理 | 停止处理并按规定删除/匿名化 |

### 6.6 报告刷新状态

| 状态 | 触发 | 展示 | 操作 |
|---|---|---|---|
| empty | 无作答 | “完成 1 次练习解锁报告” | 去练习 |
| insufficient | 所选范围无样本 ≥3 的 KP | “数据不足，还差 N 次作答” | 去练该 KP |
| fresh | 最近一次提交已计入 | 正常数据 + 更新时间 | 下钻 |
| updating | 提交后 5 分钟内未完成 | “数据更新中，预计 5 分钟内” + 旧数据时间 | 稍后刷新 |
| stale | 超过预期未更新 | “数据可能延迟” + 刷新 | 刷新/反馈 |
| error | 查询失败 | 错误 + 重试 | 重试 |

### 6.7 订阅/订单状态（V1 方向，MVP 不实现）

```
created ──▶ paying ──成功──▶ paid ──退款──▶ refunding ──▶ refunded
   │           │失败
   │           ▼
   └──────▶ closed / failed
paid ──到期──▶ expired（权益降级，数据保留）
```

MVP 不出现任何订单/支付状态与入口；V1 需补齐重复支付识别、退款、过期、自动续费默认关闭。

### 6.8 通用页面状态规范

所有 P0 页面必须实现以下状态，不允许白屏、NaN、死链、静默失败：

| 状态 | 必备元素 | 禁止 |
|---|---|---|
| loading | 骨架屏/loading 指示；超过 10 秒给“仍在加载 + 重试” | 空白页、无限转圈 |
| empty | 说明“为什么空” + 一个明确行动（去练习/去选教材/重试） | 只有“暂无数据” |
| error | 失败原因（用户能懂）+ 重试 + 返回；保留已输入内容 | 抛错码、白屏 |
| no_permission | “无权查看” + 返回；不泄露资源存在性 | 显示他人数据 |
| offline | 顶部提示 + 缓存内容/骨架 + 重试；答案本地保留 | 静默丢答案 |
| partial | 局部失败局部提示；其余模块可用 | 整页崩溃 |
| disabled | 说明为何不可用（未开放/内容准备中/已下线） | 可点击但无响应 |

### 6.9 状态与 URL/刷新/返回的一致性

1. 练习页 URL 含 `attemptId`；刷新进入同一 attempt 的当前状态（draft 恢复 / graded 结果）。
2. 报告周期、错题筛选写入 URL query，刷新/返回保留。
3. 结果态不因浏览器后退回到作答态；后退回章节页。
4. 404/403 使用独立路由，便于客服定位与埋点。
5. 任何“提交成功”提示必须对应服务端确认，不以客户端计时器伪造。

## 7. 业务规则落地

> 本章把需求基线 R-01～R-17 转成页面/交互可执行的规则。规则口径冲突时按 0.2 处理；标注 DS 的为设计补充假设。

### 7.1 教材、章节与知识点（R-01）

**层级与数据**

```
教材版本（统编/人教/沪教牛津）
  └ 学段（小学/初中）→ 年级（1–9）→ 册（上/下）→ 章节（章/节）
        └ 章节-KP 映射（多对多，带权重）
              └ 知识点 kp_id（跨版本复用）
                    ├ 题目（至少 1 主 KP）
                    ├ 掌握度（学生 × kp）
                    └ 错题聚类
```

**落地规则**

1. 教材导航为“学段 → 学科 → 版本 → 册（含年级与学期）→ 章”；知识点不是导航层级，只在章节页与题目/报告中出现。
2. 章节进度按“学生 + 版本 + 册 + 章节”隔离；切换版本不覆盖、不删除；返回原版本恢复上次章节与草稿入口。
3. KP 掌握度按“学生 + kp_id”跨版本聚合；MVP 不引入版本系数（A-04、Q-04）。
4. 章节必须至少关联 1 个 KP 才能发布练习；题目必须至少 1 个主 KP。
5. 章节树调整需版本化；已下线章节保留历史映射，学生历史记录仍可查看。
6. 年级变更：默认展示新年级当前学期教材；旧年级进度保留；不自动删除。
7. 未开放内容：入口禁用/隐藏；直接访问 URL 给“内容准备中”+ 返回，不报错。
8. 内容缺失（无微课/无例题）：不阻断练习；显示引导文案。

### 7.2 判分规则（R-03）

**题型与判分**

| 题型 | MVP 自动判分 | 判分规则 | 结果展示 | 计入掌握度 |
|---|---|---|---|---|
| 单选 | 是 | 选项 ID 完全匹配 | 对/错、正确答案、解析 | 是 |
| 多选 | 是 | 选项集合完全相等；**默认全对得分，不设部分分** | 对/错、正确答案、解析 | 是 |
| 判断 | 是 | 布尔值相等 | 对/错、正确答案、解析 | 是 |
| 填空 | 是（答案可结构化匹配） | 标准答案列表；归一化后匹配 | 对/错、参考答案、解析 | 是 |
| 主观题（简答/作文） | 否 | 展示参考答案 + 自评清单 | 明确标识“参考解析/自评” | 否 |
| 连线/排序 | MVP 不开放 | 不在题型配置中开放 | — | — |
| 听力 | MVP 不做（Q-06） | 不配置、不展示 | — | — |
| 口语 | 否 | 不做 | — | — |

**填空归一化（DS-10，待 Q-03 确认）**

1. 去首尾空格；连续空格折叠为一个；全角/半角统一；英文大小写不敏感（可配置）。
2. 仅做“字符串级”匹配；同义答案、单位换算、分数/小数等价需教研在答案列表中显式配置，不做语义推断。
3. 多个标准答案用列表维护；任一匹配即正确。
4. 未配置同义答案时，若学生答案与标准答案仅表述不同，结果页展示参考答案并引导自评/反馈，不静默判错。

**得分（DS-01，待教研确认）**

- MVP 每题等权：得分 = 正确题数 ÷ 总题数 × 100，四舍五入取整；满分 100。
- 未作答：计 0 分；结果页单独标识“未作答”；**不计入掌握度、不自动入错题本**。
- 多选：全对得分，少选/多选/错选均不得分；不设部分分（A-05）。
- 题目配置分值、主观题人工评分、部分分：V1 预留，不在 MVP 实现。

**判分输出（每题）**：是否正确、得分、我的答案、正确答案、解析、KP、错因提示（如有）、题目版本快照。

**判分性能与失败**

- 目标：端到端 P95 ≤1 秒（4G、主流中端手机、生产同构环境）；服务端判分 P95 ≤800ms（建议值）。
- 客户端不预判分数；判分中不显示对错；失败可重试；重试幂等。
- 判分服务超时：显示“判分中/重试”，不自动重复提交；结果以服务端为准。

**答案快照**

- 提交时固化题目、选项、答案、解析、KP 的版本；后续修订不改变历史作答与报告（AC-03-10）。
- 题目下线后，历史结果/错题仍按快照展示；不可重做。

### 7.3 提交与幂等（R-04）

| 场景 | 规则 |
|---|---|
| 重复点击提交 | 客户端按钮防抖 + 服务端幂等；只产生一次有效提交 |
| 网络重试 | 同一 `attempt_id` 返回同一结果；不重复计分/入错题 |
| 多端同时提交 | 先被服务端接受者生效；另一端进入结果态并提示“已交卷” |
| 提交后刷新/重进 | 进入结果态；不可改答案 |
| 判分失败 | 保留答案；重试不新建 attempt；不产生半成品结果 |
| 未答完提交 | 二次确认列出未答题号；确认后未答计 0、不入错题 |
| 已交卷修改 | 禁止；只可重做（新 attempt）或再练一组 |
| 草稿恢复 | 只恢复 draft；graded/expired 不恢复为可编辑 |

**服务端时钟与归属**：提交时间以服务端 UTC+8 为准；跨周/跨日归属按提交时间，不按客户端时间。

### 7.4 错题本（R-05～R-07）

1. **收录**：首次答错即入本；未作答不入本；同一学生同一题目唯一。
2. **字段**：首次/最近错误时间、错误次数、来源练习、错因标签、掌握状态、题目快照版本。
3. **聚类**：按 KP 分组；同 KP 下按最近错误时间倒序；可按学科/章节/KP/错因/状态/时间筛选。
4. **错因**：概念不清/计算失误/审题偏差；可跳过、可修改；不影响判分与掌握度计算。
5. **重做**：原题重做或变式；提交即时判分；重做正确更新掌握进度，重做错误累计错误次数；不覆盖原错题记录。
6. **变式**：同 KP → 同题型 → 难度 ±1 → 未做优先；与错题有实质差异（情境/数据/问法至少一项不同）；无题给同 KP 题入口，不返回空列表/原题。
7. **掌握**：连续 2 次正确、不同次练习、间隔 ≥1 自然日 → 已掌握；再错清零；可手动恢复。
8. **删除**：二次确认；软删除；报告口径同步；历史统计按匿名汇总建议处理。
9. **越权**：仅本人可见；403 不泄露存在性。
10. **题目下线**：只读快照，禁止重做/变式。

### 7.5 掌握度与学情口径（R-08）

**计算对象**：学生 × kp_id（跨教材版本聚合）。

**有效作答**

- 仅统计已提交练习中的作答；未作答不算有效作答。
- 同一题目多次作答取**最近一次**结果；先按题目去重，再取最近 10 条不同题目的最新结果（去重与取窗顺序为设计口径，待 Q-04 确认）。
- 被删除的错题不删除其历史作答统计（建议口径，R-08）。
- 主观题/自评题不计入。

**窗口与权重**

- 窗口：最近 10 次有效作答（去重后）。
- 权重：最近 3 次权重 2，其余权重 1。
- 掌握度 = 加权正确数 ÷ 加权作答数 × 100%，四舍五入取整。

**等级与样本**

| 条件 | 展示 |
|---|---|
| 有效作答 <3 | “数据不足”，不显示百分比，不参与薄弱点排序 |
| ≥80% | 已掌握 |
| 60%–79% | 待巩固 |
| <60% | 薄弱 |

**薄弱点排序**：掌握度升序 → 有效作答次数降序；报告最多 5 个，首页最多 3 个；样本 <3 不参与。

**算例（用于验收核对，非真实用户数据）**

某学生某 KP 最近 10 道不同题目的最新作答（按时间从早到晚）：

| 序号 | q1 | q2 | q3 | q4 | q5 | q6 | q7 | q8 | q9 | q10 |
|---|---|---|---|---|---|---|---|---|---|---|
| 结果 | 错 | 对 | 错 | 对 | 对 | 错 | 对 | 对 | 对 | 错 |
| 权重 | 1 | 1 | 1 | 1 | 1 | 1 | 1 | 2 | 2 | 2 |

- 加权正确数 = 1+1+1+1+2+2 = **8**
- 加权作答数 = 7×1 + 3×2 = **13**
- 掌握度 = 8 ÷ 13 = 61.54% → **62%**，等级“待巩固”。

**聚合口径（DS-07，待 Q-04 确认）**

- 学科/章节/整体掌握度 = 范围内“有效作答 ≥3 的 KP”的掌握度，按各 KP 有效作答次数加权平均，四舍五入取整。
- 若无合格 KP → “数据不足”；不把 0 个样本当作 0%。
- 示例：KP-A 80%（10 次）、KP-B 50%（5 次）、KP-C 数据不足 → (80×10 + 50×5) ÷ 15 = **70%**。

**更新与版本**

- 提交后 5 分钟内更新（建议值）；未完成显示“更新中”。
- 口径变更需版本化并公告；历史报告按当时口径快照，不回溯改写。
- 页面提供“如何计算”说明（AC-05-8）。

### 7.6 学习时长（R-09）

| 规则 | 设计定义 |
|---|---|
| 计时条件 | 前台可见 + 30 秒内有交互（点击、输入、滚动、播放） |
| 暂停 | 无交互 30 秒后暂停；再次交互恢复 |
| 不计时 | 切后台、锁屏、关闭页面、纯挂机 |
| 微课 | 按实际播放时长；暂停不计；拖动进度不重复计 |
| 时区 | UTC+8；自然周周一 00:00:00–周日 23:59:59 |
| 多端 | 同一时间窗口只计一个活跃 session（取最早开始），避免重复 |
| 展示 | 本周总时长、日均、分学科；分钟取整；<1 分钟显示“<1 分钟” |
| 口径说明 | 报告注明“仅统计前台活跃时长，无交互 30 秒暂停” |

**示例（说明口径，非真实数据）**：20:00–20:25 在线，其中 20:10–20:20 无交互 → 计 15 分钟；若同一时段另一设备也在学习，只计最早开始的 session。

### 7.10 内容、版权与审核（R-15～R-17）

1. **来源与版权**：题目、解析、微课、图片、音频必须原创或已授权；每题记录来源、作者、审核人、版权状态、授权凭证编号（内部字段）。
2. **教材同步表述**：未取得教材出版方授权，不得宣称“教材同步”，不得使用教材原文/版式/插图；只能使用课标知识点自建内容（D-01/Q-02）。
3. **发布门禁**：题干、答案、解析、≥1 主 KP、难度、题型、来源、版权状态、审核人齐全；缺一不可；章节需 ≥1 KP 映射才能发布练习。
4. **审核流程**：编写 → 交叉审校 → 发布抽检 → 线上巡检/下架；编辑与审核权限分离；日志可追溯。
5. **版本化**：题目修订生成新版本；历史作答快照不变；可查看差异、可回滚。
6. **错误处理**：线上发现答案/解析错误 → 立即下线 + 站内提示受影响用户 → 修正后重新发布；侵权通知 24 小时内下线复核（建议值）。
7. **微课权利**：出镜/配音/音乐需肖像权、著作权授权；无授权不上线。
8. **内容纠错入口**：题目详情/结果页提供“内容纠错”，工单进入运营/教研。

### 7.11 客服与投诉

| 项 | 设计 |
|---|---|
| 入口 | 个人中心“帮助与反馈”；≤3 次点击；协议页/结果页也可达 |
| 分类 | 账号问题、内容错误、隐私投诉、支付/退款（V1）、其他 |
| 记录 | 工单号、用户、问题类型、处理状态、时限 |
| 响应 | 工作日 1 个工作日内首次响应（建议值）；支付退款按 Q-13 |
| 升级 | 隐私/内容安全事件按应急预案上报；重大事件法务介入 |
| 权限 | 客服查看学习记录需工单授权 + 脱敏；不导出明文手机号 |

### 7.12 规则冲突与变更

1. 合规/未成年人 > 内容准确性/版权 > 学习闭环可用性 > 性能 > 增长 > 体验（沿用需求基线 2.5）。
2. 规则变更必须评估：页面状态、判分/掌握度历史、报告口径、AC、对外文案。
3. 涉及判分、掌握度、时长、错题掌握的变更，必须版本化口径并保留历史快照。
4. 涉及未成年人、支付、版权的变更，必须法务确认。

## 8. 数据与埋点设计

### 8.1 数据流

```
学生端（Web/H5）
   │ 业务请求 + 事件
   ▼
业务服务（账号/教材/练习/判分/错题/报告）
   │ 服务端事件（为准）           │ 作答/判分落库
   ▼                              ▼
事件采集 ──▶ 数据仓库/指标层 ──▶ P-10 指标看板
   │                              │
   └── 客户端事件（补充）          └── P-07 学情报告（按 R-08/R-09 聚合）
```

**原则**：服务端事件为准，客户端事件用于补充页面行为；同一事件有唯一 `event_id` 与去重键；时区统一 UTC+8；埋点失败不阻断主流程。

### 8.2 事件字典（MVP）

| 事件 | 触发 | 关键属性 | 来源 | 去重键 |
|---|---|---|---|---|

| `chapter_view` | 进入章节页 | chapter_id、来源 | 客户端 | session_id + chapter_id |

### 8.3 指标计算映射

| 指标 | 计算口径 | 依赖事件/数据 |
|---|---|---|
| 周有效学习学生数（北极星） | 自然周内完成 ≥2 次练习提交（每次 ≥5 题）且 ≥1 次错题重做（≥1 题）的去重学生 | practice_submit、wrong_redo |
| 激活率 | 注册后 7 个自然日内完成 ≥1 次练习提交（≥5 题）人数 ÷ 同期注册人数 | user_register、practice_submit |
| 7 日留存 | D0 注册 cohort 中 D7 有 ≥1 次练习提交或错题重做的比例 | user_register、practice_submit、wrong_redo |
| 周学习天数 | 自然周内有练习提交或错题重做的不同日期数；按学生取周均值 | practice_submit、wrong_redo |
| 错题重做正确率提升 | 首次做错前 30 天同 KP 正确率基线 vs 重做后 7–30 天同 KP 变式题正确率；按学生平均 | attempt_item、wrong_redo、question_kp |
| 付费转化率（V1） | 统计月内 ≥1 次成功支付去重用户 ÷ 月活学生 | pay_success、活跃 |
| 内容覆盖率 | 已上线章节中具备 KP 映射、≥1 例题、≥N 题、解析齐全的占比 | P-09 内容数据 |
| 抽检准确率 | 抽检题目答案/解析/KP 均正确占比；目标 ≥98%，致命错误 0 | 教研抽检 |

### 8.4 数据质量与隐私

1. **服务端为准**：注册、提交、判分、错题、支付以服务端事件为准；客户端仅补充页面行为。
2. **去重**：同一 `attempt_id` 的提交事件只计一次；重复事件按事件 ID/业务主键去重。
3. **核对**：埋点与服务端业务数据抽样核对，关键指标误差 ≤1%（建议值，AC-17-4）。
4. **时区**：统一 UTC+8；周归属按提交时间；口径变更版本化。
5. **隐私**：最小化字段；不含明文手机号/身份证/支付凭据；导出与查看按权限审批；注销后按 R-13 处理。
6. **失败降级**：埋点失败不阻断练习/支付；可补发；缺失数据在看板标注，不用 0 冒充。

### 8.6 埋点验收

**设计侧约束**

- 判分中不使用“假进度条到 100% 但无结果”的欺骗式动效；进度仅作等待反馈。
- 弱网下先展示缓存骨架与已保存答案，再同步。

### 9.2 兼容性矩阵

| 终端/浏览器 | 最低版本 | 设计要求 |
|---|---|---|
| iOS Safari | iOS 15+ | 安全区、软键盘、滚动、`100vh` 兼容 |

| 微信内置浏览器 | 微信 8.0+ | 公众号网页授权、字体缩放、视频播放 |

### 9.3 响应式、栅格与视觉规范

| 项 | 规范 |
|---|---|
| 断点 | <360 紧凑；360–430 主设计区间；431–767 大屏手机；768–1023 平板；≥1024 桌面 |
| 栅格 | 移动 4 列；平板 8 列；桌面 12 列；间距 16px；桌面内容最大 1120px |
| 间距 | 以 4/8 为基数的 token 体系（4/8/12/16/24/32）；卡片内边距 16；模块间距 16–24 |
| 字号 | 正文 16；辅助 14；说明 12；标题 18/20/24；数据强调 28–32；行高 1.6 |
| 触控 | ≥44×44 CSS px；主按钮高 48；底部 Tab 高 56 + 安全区 |
| 圆角/阴影 | 统一 token；不依赖阴影表达层级；避免过度装饰 |
| 颜色 | 正文对比度 ≥4.5:1；对错同时用图标/文字，不只靠红绿 |
| 深色模式 | MVP 不要求；如系统强制反色，保证可读 |
| 动效 | 尊重 `prefers-reduced-motion`；非必要动画可关闭；判分动效不超过 1 个循环 |

### 9.4 可访问性

1. 语义化结构：标题层级、列表、表单 label、按钮可聚焦；桌面键盘可操作。
2. 触控目标 ≥44×44；相邻可点击元素间距 ≥8。
3. 对错/状态不只靠颜色：加“✓/✗ + 对/错”文字。
4. 图表提供文字摘要（如“近 4 周掌握度：62%、65%、68%、70%”）。
5. 系统字号放大 200% 不破坏布局；不截断关键按钮文案。
6. 焦点可见；弹窗焦点锁定；Esc/返回可关闭。
7. 视频/微课提供暂停、音量、全屏；不自动播放声音。

### 9.5 安全与隐私设计（前端/交互层）

| 项 | 设计要求 |
|---|---|
| 传输 | 全站 HTTPS；不在 URL 放手机号、验证码、token |
| 展示 | 手机号中间 4 位脱敏；日志/错误提示不出现完整手机号 |
| 本地存储 | 不存明文敏感信息；退出登录清除 token 与草稿缓存 |
| 会话 | 登录态过期先保存草稿再跳登录；回跳不丢目标 |
| 越权 | 学生端仅访问本人资源；403 不泄露存在性；内部后台独立入口与最小权限 |
| 提交 | 防重复提交、防重放；关键操作二次确认 |
| 未成年人 | 监护人同意前不采集；不采集真实姓名/学校/班级/精确地址 |
| 第三方 | MVP 不接入广告 SDK；第三方服务在隐私政策列明 |
| 支付（V1） | 不存银行卡/支付密码；回调验签、幂等；自动续费默认关闭 |

### 9.6 降级与容错

| 依赖故障 | 用户可见 | 设计兜底 |
|---|---|---|
| 判分服务超时 | “判分中/判分失败，请重试” | 答案保留；重试幂等；结果可稍后查询；不显示假分数 |
| 题库不足 | “本章节题目准备中” | 推荐同册其他章节；不生成残缺练习 |
| 报告计算延迟 | “数据更新中，预计 5 分钟内” | 展示上次更新时间；可刷新；不把旧数据标新 |
| 微课/CDN 失败 | “视频加载失败，重试” | 不阻断练习；可跳过 |
| 内容下线 | “内容已下线” | 错题保留快照；首页不再推荐；给返回入口 |
| 短信通道故障 | “验证码发送失败，请稍后重试” | 保留手机号输入；提供客服入口 |
| 微信授权失败 | “未获得授权，可用手机号登录” | 回退路径；保留 redirect |
| 埋点失败 | 用户无感 | 不阻断主流程；服务端补发/降级 |
| 网络离线 | 顶部提示“网络不可用” | 本地保存；恢复后同步；离线页可重试 |

### 9.7 可观测与运营开关

1. 前端错误、API 成功率/延迟、判分失败率、支付失败率（V1）、内容发布失败率有监控与告警。
2. 功能开关：分层练入口、城市卷、支付入口、PWA 引导默认关闭；可按城市/版本灰度。
3. 内容紧急下线：单题/章节/版本三级；下线后学生端即时不可见（建议 1 分钟内）。
4. 公告模板：内容错误、服务延迟、支付异常、隐私事件。
5. 值班与回滚：灰度 5%→25%→100%，每档观察 ≥48 小时（建议值）；S1 缺陷/支付异常/判分错误率异常触发回滚。

### 9.8 文案与合规用语

| 类型 | 禁止 | 建议 |
|---|---|---|
| 效果承诺 | “保过”“提分保证”“最牛”“第一” | “帮助巩固知识点”“记录学习过程” |
| 排名比较 | “超过 90% 同学”“班级排名” | 只呈现个人变化 |
| 诱导 | “分享解锁”“连续登录领奖”“限时逼单” | 无诱导；MVP 无付费 |
| 教材表述 | 未授权时“教材同步”“官方指定” | “课标知识点”“配套练习”（按授权状态） |
| 错题 | “你太粗心”“这么简单都错” | “再看看这道题的关键信息” |
| 未成年人 | 收集真实姓名/学校/班级 | 仅昵称/年级/城市（可选） |
| 焦虑营销 | “再不学就落后” | 中性、鼓励、可执行 |
