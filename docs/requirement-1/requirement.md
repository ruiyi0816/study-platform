## 1. 需求结论

### 1.1 一句话定位

面向广东地区（首发广州、深圳）小学 1–6、初中 7–9 学生，提供 Web 端语文、数学、英语的教材同步「学—练—测—评」自主学习闭环；MVP 全免费，核心验证“同步练 → 错题重做 → 学情反馈”能否形成周频学习习惯。

### 1.2 MVP 必须成立的四个闭环

| 闭环 | 必须成立的事实 | 对应需求 |
|---|---|---|
| 内容闭环 | 学生能从学段、学科、版本、册、章进入章节，看到知识点、微课/例题与可做的题；题目有答案、解析、知识点与来源 | F-02、F-03、F-16 |
| 学习闭环 | 学生完成一次同步练，得到即时判分与解析；错题自动入本，可按知识点聚类并重做 | F-03、F-04 |
| 数据闭环 | 作答、错题、重做、时长被记录，掌握度与学情报告可解释、可复核 | F-05、F-17 |
| 合规闭环 | 协议与隐私政策可访问；未成年人取得监护人同意；账号可注销；内容版权可追溯 | F-15、F-18 |

### 1.3 MVP 范围一句话

**用户端只做学生端、只做 Web、只做广东、只做 6 个学科组的语数英同步练与错题复盘，全免费。**（内部内容后台与数据看板不计入用户端范围）

明确不做：原生 App、直播课、B 端学校版、独立家长端、AI 答疑、学习计划打卡、物理化学、高中、北师大版数学；听力/口语自动评测默认不做，待 Q-06 确认。

### 1.4 必须先决策的五件事（阻断内容生产或上线）

| 决策 ID | 决策事项 | 为什么阻断 | 最晚决策点 | Owner | 未决时的默认处理 |
|---|---|---|---|---|---|
| D-01 | 沪教牛津版英语教材与配套内容授权是否落地 | 未授权则不能以“教材同步”名义上线英语；直接搬运存在版权风险 | 内容生产启动前（M1） | 商务/法务 | 英语模块不以上述教材上线；是否改用课标知识点内容由 Q-02 决定 |
| D-02 | MVP 自动判分范围（主观题、多选题部分分、听力/口语） | 决定 F-03 的题量、判分引擎、教研工作量与 1 秒判分承诺是否成立 | 研发排期锁定前（M1） | 产品/教研 | 仅客观题自动判分；多选全对得分；主观题不自动判分；听力/口语不做 |

- 目标、用户、MVP 范围、业务边界与验收口径已具备可执行版本，可进入方案设计与研发准备。
- 内容生产与英语模块上线受 D-01 约束，自动判分范围受 D-02 约束，支付上线受 D-04 约束；不得在决策关闭前对外承诺。
- 上游 PRD 的三项待定事项（授权、首发城市、教研招聘）已分别转为 Q-02、Q-01、Q-14，并补充了内容后台、埋点、账号注销、未成年人保护等原 PRD 未展开但 MVP 必须成立的需求。

## 2. 背景与目标

### 2.1 背景与问题假设

以下为产品假设，需在 MVP 中用数据验证，不作为既成事实：

| 编号 | 假设 | 验证方式 |
|---|---|---|
| H-01 | 学生课后练习缺少与教材章节精确对应的轻量入口，找题、对答案成本高 | 访谈 + 首次练习完成率 |
| H-02 | 错题只抄不做、缺少变式题，是重复犯错的主要原因 | 错题重做率、重做后同知识点正确率 |
| H-03 | 家长希望看到学习过程，但不愿为学生增加新的 App/设备负担 | 家长周报打开率、V1 付费意愿 |
| H-04 | Web/微信内 H5 足以覆盖首发场景，能降低安装与获客门槛 | 激活率、7 日留存、终端分布 |
| H-05 | 教研共建的“知识点主数据 + 教材映射”可让同一题库服务多版本教材 | 多版本章节覆盖率、题目复用率 |

### 2.2 产品目标

| 目标 | 说明 | 衡量方式 |
|---|---|---|
| G-01 学得进去 | 学生 3 步内从首页进入当前章节练习；单次练习可在手机竖屏完成 | 路径埋点、可用性测试 |
| G-02 错得明白 | 错题自动收录、可标错因、可做变式；掌握度随作答更新 | 错题重做率、掌握度变化 |
| G-03 看得见进步 | 学生/家长能看懂薄弱点、时长与趋势，且口径可解释 | 报告查看率、口径复核 |
| G-04 内容可复用 | 知识点主数据与教材映射分离，新增版本只增映射层 | 版本扩展工时、映射覆盖率 |
| G-05 商业可验证 | V1 末验证家长为增值内容付费的意愿 | 付费转化率、退款率 |

### 2.3 成功指标（目标值来自上游 PRD，属于待验证假设）

| 环节 | 指标 | MVP/V1 目标 | 口径位置 |
|---|---|---|---|
| 北极星 | 周有效学习学生数 | 不作为 MVP 硬门槛，作为发布后 4 周观察指标 | §8.4 |
| 激活 | 注册 → 完成首次练习 | ≥ 60% | §8.4 |
| 留存 | 7 日留存 | ≥ 25% | §8.4 |
| 习惯 | 周学习天数 | ≥ 3 天 | §8.4 |
| 效果 | 错题重做正确率提升 | ≥ 20 个百分点 | §8.4 |
| 商业（V1 末） | 付费转化率 | 3–5% | §8.4 |

> 指标目标不是承诺值。MVP 上线前没有历史基线，发布后先建立 4 周基线，再判断目标是否需要调整。

### 2.4 非目标（本阶段明确不做）

- 不做面向义务教育阶段的学科类校外培训服务，不做直播课、录播课售卖、教师带班服务。
- 不做原生 iOS/Android App；不做独立家长端 App；不做 B 端学校版；不做开放 API。
- 不做高中内容、物理化学内容、北师大版数学内容。
- 不做社交、排名、班级对比、公开学习圈。
- 不做 AI 自动批改作文/口语；不做 AI 答疑（P2）。
- 不做广告变现；不做诱导分享、诱导付费。

### 2.5 冲突时的优先级

当需求冲突或资源不足时，按以下顺序取舍：

1. 合规与未成年人保护；
2. 内容准确性与版权合法性；
3. 学习闭环可用性（能练、能判、能复盘）；
4. 性能与稳定性；
5. 增长与商业化；
6. 体验锦上添花。

### 3.3 核心场景剧本

#### S-01 课后同步练（MVP 主场景）

- **前置**：学生已登录；已选择学段、学科、教材版本、册；处于当前学期。
- **主路径**：
  1. 首页显示“今日任务/继续学习”，点击进入上次章节或推荐章节；
  2. 章节页显示知识点清单、微课（可选）、例题与“开始练习”；
  3. 选择难度（MVP 默认基础；分层练为 V1）；
  4. 逐题作答，支持上一题/下一题、答题卡跳转；
  5. 提交，系统判分并展示总分、对错、正确答案、解析、知识点；
  6. 错题自动入本；掌握度与报告更新；
  7. 学生可进入错题本标错因、看重做推荐。
- **异常路径**：
  - 断网/切后台：答案本地保留，恢复后继续；提交失败可重试，不重复计分；
  - 超时/重复点击提交：只产生一次有效提交；
  - 题目解析缺失：该题不得发布；线上发现则下线并提示；
  - 未答完提交：二次确认，展示未答题号。
- **成功标准**：从进入章节到看到解析，手机竖屏可完成；判分 P95 ≤ 1 秒；错题本出现该错题。

#### S-02 错题复盘（MVP 主场景）

- **前置**：错题本中已有错题。
- **主路径**：
  1. 进入错题本，按学科/章节/知识点/错因筛选；
  2. 打开错题详情，看原题、我的答案、正确答案、解析、错误次数；
  3. 选择错因标签（概念不清/计算失误/审题偏差，可跳过）；
  4. 点击“重做”或“变式题”；
  5. 提交后即时判分；连续 2 次正确（不同次练习）标记“已掌握”；
  6. 掌握度与报告更新，薄弱点排序变化。
- **异常路径**：无变式题时给出明确提示与“继续练同知识点题”入口，不返回空列表；错题删除需二次确认。
- **成功标准**：错题可被找到、可重做、状态可变化；报告中的薄弱点与错题本一致。

#### S-03 考前专项/组卷（V1）

- **前置**：学生已有至少 1 个薄弱知识点；题库有足够题目。
- **主路径**：选择薄弱知识点或组卷参数 → 系统生成学习路径/试卷 → 作答 → 判分 → 报告与错题本更新。
- **成功标准**：生成结果覆盖所选知识点；无足够题目时明确告知缺口，不生成“残缺卷”。

#### S-04 家长周报与订阅（V1 末）

- **前置**：学生账号已绑定家长手机号；家长在微信内打开周报/支付页。
- **主路径**：查看本周学习时长、练习次数、掌握度变化、薄弱点 → 选择订阅方案 → 支付 → 权益生效 → 下期周报继续推送。
- **异常路径**：支付失败/重复支付/退款/订阅过期均有明确状态与客服入口。
- **成功标准**：家长无需注册独立 App；支付后学生端权益即时生效；退款可追踪。

#### S-05 教研上架内容（MVP 内部场景）

- **前置**：教研已登录内容后台，具备编辑权限。
- **主路径**：新建/导入章节 → 关联知识点 → 录入题目、答案、解析、难度、题型、来源 → 提交审核 → 审核人通过 → 发布 → 学生端可见。
- **异常路径**：必填缺失不能发布；审核驳回可修改；已发布内容可下线/回滚；题目修订不影响历史作答。
- **成功标准**：不依赖研发即可完成一个章节的内容上架；发布前校验与操作日志可查。

### 3.4 场景边界

| 维度 | 边界 |
|---|---|
| 终端 | 手机浏览器为主，兼容桌面浏览器；不做原生 App；微信内 H5 可用 |
| 网络 | 4G/5G/WiFi 为主；需容忍 3G/弱网、短时断网、切后台 |
| 时间 | 课后 16:00–21:00 为高峰；不设直播/实时课堂，允许异步 |
| 地点 | 家庭为主，学校场景不承诺；不依赖校园网 |
| 账号 | 一个学生一个账号；MVP 不设独立家长账号；V1 家长以手机号+验证方式支付 |
| 监护 | 未满 14 周岁需监护人同意；1–2 年级默认家长协助首次配置 |
| 设备 | 屏幕宽度 320–430 CSS px 竖屏为主；兼容常见平板/桌面 |
| 内容 | 仅首发 6 个学科组、3 个教材版本；其他入口明确“敬请期待” |

### 3.5 关键体验原则

1. **三步进入练习**：首页 → 章节 → 开始练习，不超过 3 次点击（已选教材前提下）。
2. **一次练习可中断**：默认 10–15 题、10–15 分钟（建议值），支持草稿恢复。
3. **不排名、不攀比**：报告只呈现个人数据，不出现班级/地区排名。
4. **不诱导**：不做分享解锁、连续登录强迫、付费弹窗打断练习。
5. **可解释**：掌握度、时长、薄弱点都能看到“怎么算的”。

## 5. 业务规则与边界

### 5.1 教材、章节与知识点

**R-01 知识点主数据**

- 知识点（kp_id）是跨教材版本复用的最小单元，包含：学科、学段、名称、前置依赖、考纲映射、状态。
- 教材章节通过映射表关联 kp_ids；版本差异只体现在映射层，不复制知识点。
- 一个知识点可被多个版本、多个章节引用；一个章节可包含多个知识点。
- 知识点前置依赖在 MVP 仅作为数据字段记录，不驱动学习路径；V1 专项突破再使用。
- 章节进度按“学生 + 教材版本 + 册 + 章节”隔离；知识点掌握度按“学生 + kp_id”聚合（建议口径，见 A-04）。
- 切换教材版本不得删除或覆盖原版本进度；返回原版本应恢复上次位置。

**R-02 题目主数据**

- 每题必须包含：题干、题型、选项（如适用）、正确答案、解析、至少 1 个 kp_id、难度（1 基础/2 提升/3 挑战）、来源、版权状态、审核状态、版本号。
- 缺答案、缺解析、缺知识点、版权状态不明的题目不得发布。
- 题目修订产生新版本；历史作答记录保存作答时的题目与答案快照，报告不因后续修订而改变。

### 5.2 判分规则

**R-03 自动判分范围（默认 A-05，待 D-02/Q-03 确认）**

| 题型 | MVP 是否自动判分 | 规则 |
|---|---|---|
| 单选 | 是 | 选对得分，选错不得分 |
| 多选 | 是 | 默认全对得分，不设部分分；如教研要求部分分，须在 Q-03 明确规则后实现 |
| 判断 | 是 | 对/错二值判分 |
| 填空 | 是（答案可结构化匹配时） | 支持标准答案列表、大小写/空格/全半角归一；同义答案需教研配置 |
| 连线/排序 | 视实现而定 | 若 MVP 不做，不得在题型配置中开放 |
| 阅读理解简答 | 否 | 展示参考答案与自评清单，不计入自动掌握度 |
| 作文 | 否 | 不做自动批改；可展示评分维度与自评 |
| 听力 | 待 Q-06 | 若纳入，需补充音频播放、重播限制、听力判分验收 |
| 口语 | 否 | 不做 |

- 判分以题目当前发布版本的答案为准；提交时固化答案快照。
- 判分结果包含：得分、对错、正确答案、解析、知识点、错因提示（如有）。
- 主观题不自动判分时，页面必须明确标识“参考解析/自评”，不得伪装成自动判分。

**R-04 提交与幂等**

- 一次练习对应一个 attempt_id；重复提交、网络重试、多端同时提交，只允许一个有效结果。
- 已交卷的练习不可修改答案；可查看解析、加入错题本、发起重做。
- 未交卷退出保存草稿；草稿保留 24 小时（建议值），超时提示重新开始。

### 5.3 错题本规则

**R-05 收录与去重**

- 首次提交答错即自动入本；同一学生同一题目只保留一条错题记录，累计错误次数。
- 记录字段：首次错误时间、最近错误时间、错误次数、来源练习、错因标签、掌握状态。
- 重做仍错继续累计；重做正确不删除记录，直到满足“已掌握”规则。

**R-06 掌握与移出**

- 连续 2 次重做正确（不同次练习，至少间隔 1 个自然日，建议值）标记“已掌握”，移出待复习列表，保留历史。
- 学生可手动恢复为“待复习”；恢复后重新计入薄弱点。
- 错题删除需二次确认；删除后报告口径同步更新，历史统计保留匿名汇总（建议）。

**R-07 变式题**

- 变式题优先匹配：同 kp_id → 同题型 → 难度 ±1 → 未做过优先。
- 无可用变式题时，提示“暂无变式题”，并提供同知识点题目入口；不得返回空列表或重复原题。
- 变式题必须与错题有实质差异（题干情境/数据/问法至少一项不同），不得只改数字。

### 5.4 分层练规则（V1）

- 三档：基础（难度 1）、提升（难度 2）、挑战（难度 3）。
- 默认基础；切换难度需确认“将重新取题，当前未提交练习不保留”。
- 每档题量与题型由教研配置；同一练习内不重复出题。
- 掌握度统计包含所有难度作答，不因分层而隔离。

### 5.5 掌握度与学情口径

**R-08 掌握度（建议口径，待 Q-04 确认）**

- 统计对象：学生 × kp_id，跨教材版本聚合。
- 有效作答：已提交练习中的作答；同一题多次作答取最近一次；被删除的错题不删除其历史作答统计（建议）。
- 窗口：最近 10 次有效作答。
- 权重：最近 3 次权重 2，其余权重 1。
- 掌握度 = 加权正确数 ÷ 加权作答数 × 100%，四舍五入取整。
- 样本不足 3 次：显示“数据不足”，不显示百分比，不参与薄弱点排序。
- 等级：≥80% 已掌握；60%–79% 待巩固；<60% 薄弱。
- 薄弱点排序：先按掌握度升序，再按有效作答次数降序；最多展示 Top 5。
- 页面提供“如何计算”说明，口径变更需版本化并公告。

**R-09 学习时长**

- 仅统计前台活跃且 30 秒内有交互（点击、输入、滚动、播放）的时长；无交互 30 秒后暂停计时。
- 切后台、锁屏、关闭页面不计时；微课按实际播放时长计，暂停不计。
- 统计时区固定为 UTC+8；自然周为周一 00:00:00 至周日 23:59:59。
- 同一账号多端同时学习，同一时间窗口只计一个活跃 session（取最早开始的 session），避免重复计时。
- 报告展示“本周总时长/日均时长/分学科时长”，并注明统计口径。

### 5.6 城市与教材版本

**R-10 城市维度**

- city 枚举：gz（广州）、sz（深圳）、generic（通用）。
- 学生首次进入教材选择时选择城市；个人中心可修改；修改只影响后续推荐/试卷，不改变历史掌握度。
- 城市用于题库标签、城市模考卷、运营内容；不用于公开排名或跨城市对比。
- 不强制使用 IP 定位；如做推荐，必须允许用户修改，且不因拒绝定位阻断使用。
- 城市卷必须标注适用城市、年份、来源；无匹配城市卷时使用 generic 兜底，并明确提示。

**R-11 教材版本切换**

- 切换版本不丢原版本章节进度；原版本进度独立保存。
- 知识点掌握度跨版本按 kp_id 聚合；如教研认为不同版本要求差异大，需在 Q-04 中定义“版本系数”，未定义前不启用。
- 切换后首页“继续学习”显示当前版本进度；不混用其他版本章节。
- 年级变更由用户在个人中心确认修改，或按学年提示确认；历史年级进度保留，不自动删除；默认展示新年级当前学期教材。

### 5.7 免费与付费边界

**R-12 免费/付费（默认 A-06，待 Q-05 确认）**

- MVP 全免费：不出现付费墙、不采集支付信息、不展示订阅价格。
- V1 末上线订阅：价格区间 29–49 元/月、199–299 元/学期（来自上游 PRD，最终以 Q-05 为准）。
- 默认付费权益：专项突破、智能组卷、城市模考卷、进阶学情报告；同步练、错题本、基础报告保持免费。
- 家长支付、学生使用；支付页需展示监护人须知并由支付人确认；具体验证方式由 Q-05/Q-13 确定；自动续费默认关闭，如开启必须显著提示并可随时取消。
- 退款规则、客服入口、订单查询必须在上线前明确（Q-13）。
- 不得因未付费而删除学生已产生的学习数据；过期后只读或降级，不丢失错题与进度。

### 5.8 账号与未成年人

**R-13 账号**

- 一个手机号对应一个学生账号；微信 openid/unionid 可绑定同一账号，避免重复注册。
- 手机号仅用于登录、安全验证、必要的服务通知；不默认用于营销。
- 账号注销入口不超过 3 次点击可达；注销前告知影响；注销后建议 15 个工作日内删除或匿名化（最终时限以隐私政策与法务确认为准），法律法规另有规定的除外。
- 学生可查询、更正自己的昵称、年级、教材、城市等信息；数据导出可通过客服申请（P1 产品化）。

**R-14 未成年人保护**

- 未满 14 周岁注册需监护人同意：独立勾选、可查看监护人须知；未同意不收集个人信息。
- 最小化采集：MVP 不采集真实姓名、学校、班级、精确地址；支付场景按法规与支付机构要求采集。
- 不做公开社交、不做排名、不做用户生成内容公开展示。
- 不投放第三方广告；不做诱导分享、诱导付费、连续打卡强迫。
- 防沉迷提示（建议值，待法务/产品确认）：连续使用 40 分钟提醒休息；22:00–08:00 不发送营销/学习提醒推送。
- 家长周报仅向已绑定家长展示，不向学生公开家长支付信息。

### 5.9 内容、版权与合规

**R-15 内容版权**

- 题目、解析、微课、图片、音频必须原创或已获授权；禁止直接搬运教材、教辅、他人在线题库。
- 每道题记录来源、作者、审核人、版权状态、授权凭证编号（内部字段）。
- 教材同步需取得教材出版方授权；未取得授权时，只能使用课标知识点自建内容，且不得宣称“教材同步”、不得使用教材原文/版式/插图。
- 收到有效侵权通知后 24 小时内下线并复核（建议值）；建立内容下架与替换流程。
- 微课出镜/配音/音乐需有肖像权、著作权授权。

**R-16 合规定位**

- 产品定位为自主学习工具/校内信息化辅助，不提供面向义务教育阶段的学科类校外培训服务。
- 不做直播授课、不做教师带班、不承诺提分、不宣传“保过/提分保证”。
- 广告：MVP 无第三方广告；V1 及以后如引入，需单独评估未成年人保护与广告合规。
- 备案与资质：ICP 备案、公安联网备案、等保、教育移动互联网应用程序备案适用性、支付资质由法务/财务确认（D-04）。未完成公开上线所需备案不得发布。

**R-17 内容审核与发布**

- 流程：教研编写 → 交叉审校 → 发布抽检 → 线上巡检/下架。
- 发布前必填校验：题干、答案、解析、kp_id、难度、题型、来源、版权状态、审核人。
- 审核权限与编辑权限分离；操作日志留存，可追溯。
- 已发布题目修订需版本化；历史作答不受影响。
- 线上发现答案/解析错误，立即下线并通知受影响用户（站内提示），修正后重新发布。

### 5.10 客服与投诉

- 提供可发现的“帮助与反馈/投诉举报”入口；MVP 至少支持账号、内容错误、隐私三类问题。
- 响应时效（建议值）：工作日 1 个工作日内首次响应；支付退款类按 Q-13 执行。
- 投诉与举报记录留存，重大隐私/内容安全事件按应急预案上报。

### 6.3 P0 功能详细验收

#### 6.3.1 F-01 账号与登录

**目标**：学生能低门槛、安全地进入学习；微信内可一键授权；未成年人取得监护人同意。

**规则**：手机号+短信验证码；微信 H5 授权（微信公众号网页授权，不是小程序）；同一手机号唯一账号；协议非默认勾选；未满 14 周岁需监护人同意。

**验收标准**：

| AC | 检查条件 | 验收方法 |
|---|---|---|
| AC-01-1 | 手机号+验证码可注册/登录；验证码 6 位、5 分钟有效、60 秒可重发；连续错误 5 次锁定 10 分钟（建议值） | 功能测试 |
| AC-01-2 | 微信内打开 H5 可完成公众号网页授权登录；拒绝授权时可回退手机号登录，不阻断 | 真机演示 |
| AC-01-3 | 未登录访问受保护页面跳转登录；登录后回到原页面/原章节，不丢深链 | 功能测试 |
| AC-01-4 | 同一手机号重复注册不产生第二个账号；微信与手机号可绑定到同一账号 | 功能测试 |
| AC-01-5 | 首次登录前展示用户协议、隐私政策、未成年人保护规则；默认不勾选；拒绝后不收集个人信息 | 演示 + 法务审阅 |
| AC-01-6 | 未满 14 周岁注册流程包含监护人同意；未同意不能完成注册 | 功能测试 |
| AC-01-7 | 登录失败提示不泄露“手机号是否已注册”；验证码接口有频率限制 | 安全测试 |
| AC-01-8 | 账号注销入口 ≤3 次点击可达；注销前告知影响；注销后按 AC-15-2 处理 | 功能测试 |

**异常/边界**：短信通道故障有提示与重试；微信授权回调失败可回退；同一设备切换账号不串数据；退出登录后本地缓存清除敏感信息。

**依赖**：微信公众号认证服务号/AppID（Q-09）、短信服务商、隐私政策文本（F-18）。

#### 6.3.2 F-02 教材章节选择

**目标**：学生能准确找到当前教材章节；切换版本不丢进度。

**规则**：学段 → 学科 → 版本 → 册 → 章 五级；默认定位当前学期（建议规则：UTC+8 的 9 月 1 日–次年 1 月 31 日为上册，2 月 1 日–8 月 31 日为下册，运营商可按校历配置覆盖）；未开放内容明确提示；城市仅做推荐。

**验收标准**：

| AC | 检查条件 | 验收方法 |
|---|---|---|
| AC-02-1 | 五级选择均可操作；每级有默认/记忆；默认学期按 UTC+8 当前日期计算 | 功能测试 |
| AC-02-2 | 6 个学科组所用 3 类教材版本的章节树与教研审定稿一致：节点名称、层级、顺序 100% 匹配 | 内容抽检 |
| AC-02-3 | 切换教材版本后，原版本章节进度保留；返回原版本恢复上次章节与答题状态 | 功能测试 |
| AC-02-4 | 章节页展示知识点清单、微课（如有）、例题、练习入口；内容缺失时显示“内容准备中”，无空白页/死链 | 演示 |
| AC-02-5 | 未开放年级/学科/版本入口禁用或隐藏；直接访问 URL 显示友好提示，不报错 | 功能测试 |
| AC-02-6 | 城市推荐默认版本可配置；用户可手动修改；修改不影响历史掌握度 | 功能测试 |
| AC-02-7 | 章节树加载失败有重试；弱网下不白屏 | 弱网测试 |
| AC-02-8 | 微课可播放/暂停/续播/全屏；播放失败有重试；无微课章节不阻断练习 | 功能测试 + 弱网测试 |

**异常/边界**：教材版本下线/更名需保留历史映射；章节调整需版本化；学生跨年级升级不丢旧年级进度。

**规则**：题型范围按 R-03；判分 1 秒内（P95）；提交幂等；草稿恢复；解析缺失不发布；历史作答快照。

**验收标准**：

| AC | 检查条件 | 验收方法 |
|---|---|---|

| AC-03-2 | 支持单选、多选、判断、填空（答案可结构化匹配）；不支持题型不出现在配置中 | 功能测试 |
| AC-03-3 | 提交后 P95 ≤1 秒展示得分、对错、正确答案、解析、知识点（4G、主流中端 Android/iPhone、生产同构环境） | 性能测试 |
| AC-03-4 | 解析缺失的题无法发布；线上解析异常时该题可下线并提示 | 内容抽检 + 功能测试 |
| AC-03-5 | 未答完提交有二次确认并展示未答题号；可返回修改 | 功能测试 |
| AC-03-6 | 断网/切后台答案不丢；恢复后可继续；提交失败可重试 | 弱网/真机测试 |
| AC-03-7 | 重复点击提交、网络重试、多端同时提交只产生一次有效结果，不重复计分/入错题 | 功能测试 + 接口测试 |
| AC-03-8 | 中途退出保存草稿，24 小时内可恢复；超时提示重新开始 | 功能测试 |
| AC-03-9 | 交卷后不可改答案；可看解析；错题自动进入错题本 | 功能测试 |
| AC-03-10 | 题目/答案修订不影响历史作答与报告；历史记录可追溯到作答时版本 | 数据核对 |
| AC-03-11 | 主观题（如启用）明确标识“参考解析/自评”，不计入自动判分与掌握度 | 演示 + 数据核对 |

**异常/边界**：题库不足时提示“本章节题目准备中”，不生成残缺练习；判分服务超时有“判分中/重试”状态；多端同时答题以先提交为准，另一端提示已交卷。

**依赖**：题库（F-16）、判分服务、草稿存储、埋点（F-17）。

#### 6.3.4 F-04 错题本

**目标**：错题自动收录、按知识点聚类、可重做、可看到状态变化。

**规则**：按 R-05、R-06、R-07；同题去重；错因可跳过；变式题有实质差异；删除二次确认。

| AC-04-2 | 支持按学科、章节、知识点、错因、掌握状态、时间筛选；列表分页/加载更多可用 | 功能测试 |
| AC-04-3 | 错因标签三选一（概念不清/计算失误/审题偏差），可跳过、可修改；不影响判分 | 功能测试 |

| AC-04-6 | 变式题同 kp、难度 ±1、未做优先；无题时提示并给同知识点入口，不返回空列表/原题 | 功能测试 + 内容抽检 |
| AC-04-7 | 错题本跨设备同步；删除需二次确认；删除后报告口径同步更新 | 功能测试 |
| AC-04-8 | 错题本为空时有引导（去练习/去选章节），不出现空白页 | 演示 |
| AC-04-9 | 错题数据仅本人可见；越权访问他人错题返回无权限 | 安全测试 |

**异常/边界**：题目已下线时错题仍可看历史快照，但不可重做；变式题耗尽时提示；大量错题（如 500 条）列表性能可接受。

**依赖**：练习提交（F-03）、题库变式关系（F-16）、掌握度（F-05）。

**异常/边界**：批量导入失败有行级错误报告；并发编辑有冲突提示；误下线可恢复；删除采用软删除。

**依赖**：题库/内容存储、对象存储（微课）、权限系统。若采购现成系统，则本项转为集成验收（Q-11）。

#### 6.3.10 F-18 合规与未成年人保护

**验收标准**：

| AC | 检查条件 | 验收方法 |
|---|---|---|
| AC-18-1 | 用户协议、隐私政策、未成年人个人信息保护规则可访问；首次登录前展示；非默认勾选 | 演示 + 法务审阅 |

**依赖**：法务文本、备案/资质（D-04）、客服流程、推送服务。

#### 6.3.11 F-19 首页/学习中心

**目标**：学生登录后 3 步内进入当前学习任务；新用户有明确起点；薄弱点提示有证据、可下钻。

**规则**：首页主区块不超过 3 个（今日任务/继续学习/薄弱点）；今日任务优先级为“未完成草稿 > 上次练习章节的下一节 > 当前学期首个已开放章节”；推荐只来自当前教材版本与已开放内容；不展示排名、广告、付费弹窗；无数据有引导。

**验收标准**：

| AC | 检查条件 | 验收方法 |
|---|---|---|
| AC-19-1 | 首页展示今日任务、继续学习、薄弱点提示、选教材入口；新用户无数据时引导选教材，不出现空白页/死链 | 演示 |
| AC-19-2 | 已选教材前提下，存在未完成草稿时“继续学习”优先恢复草稿；无草稿时展示最近章节；从首页到开始练习不超过 3 次点击 | 功能测试 |
| AC-19-3 | 今日任务按当前教材版本、当前学期、未完成/推荐章节生成；不推荐未开放内容；无任务时给“去选章节”入口 | 功能测试 |
| AC-19-4 | 薄弱点最多展示 3 个；样本 <3 不展示；点击可下钻到知识点题目/错题；与 F-05 报告一致 | 数据核对 |
| AC-19-5 | 首页不出现排名、广告、诱导分享、付费弹窗（MVP） | 产品检查 |
| AC-19-6 | 首屏 LCP P75 ≤2.5 秒（4G，建议值）；加载失败有重试；弱网不白屏 | 性能/弱网测试 |
| AC-19-7 | 切换教材版本或城市后，首页推荐随之更新，不混用其他版本章节 | 功能测试 |

**异常/边界**：无网络显示缓存任务骨架与重试；内容下线后首页不再推荐；多端登录首页状态一致；未登录访问首页引导登录但不泄露个人数据。

**依赖**：F-02、F-03、F-05、F-17。

### 6.6 跨功能通用验收

所有 P0 页面/接口必须满足：

1. **加载/空/错/无权限**四态齐全，不出现白屏、NaN、死链。
2. **重复提交**幂等；表单有前端校验与服务端校验。
3. **越权**：学生只能访问自己的数据；内部后台按角色授权。
4. **时区**：统一 UTC+8；跨日/跨周边界正确。
5. **文案**：不出现“保过/提分保证/最牛”等违规或绝对化用语。
6. **可观测**：关键失败有日志、有告警、可定位。
7. **降级**：判分、报告、题库任一依赖故障时，主流程有明确提示与重试，不静默失败。

## 8. 数据模型与指标口径

| content_audit_log | 操作人、对象、动作、前后值、时间 | 内容追溯 |

### 8.2 关键约束

- 题目必须至少关联 1 个 kp；章节必须至少关联 1 个 kp 才能发布练习。
- 同一学生同一题目在错题本中唯一。
- 同一 attempt 的重复提交只产生一条有效结果。
- 历史作答保存题目/答案快照版本，题目修订不回溯改变历史报告。
- 城市、教材版本、难度、题型为可配置枚举，避免硬编码。
- 删除采用软删除；个人信息注销按 R-13 删除/匿名化。

| user_login | 登录成功 | 方式、终端 |

| practice_submit | 提交练习 | attempt_id、得分、耗时、题量、正确率 |

### 8.4 指标口径

| 指标 | 定义 | 备注 |
|---|---|---|
| 周有效学习学生数（北极星） | 自然周（UTC+8）内，完成 ≥2 次练习提交（每次 ≥5 题）且完成 ≥1 次错题重做（≥1 题）的去重学生数 | 练习含同步练/分层练/专项/组卷；不含只看微课 |
| 激活率 | 注册后 7 个自然日内完成 ≥1 次练习提交（≥5 题）的人数 ÷ 同期注册人数 | 注册当日为 D0 |
| 7 日留存 | D0 注册 cohort 中，D7 当天有 ≥1 次练习提交或错题重做的用户数 ÷ cohort 人数 | 也可补充 D7–D8 窗口，需固定口径 |
| 周学习天数 | 自然周内有 ≥1 次练习提交或错题重做的不同日期数；按学生取周均值 | 目标 ≥3 天 |
| 错题重做正确率提升 | 学生错题首次做错前 30 天同 kp 正确率（基线）与重做后 7–30 天同 kp 变式题正确率（结果）之差；按学生平均 | 无基线样本的学生不纳入；目标 ≥20pp |
| 付费转化率（V1） | 统计月内至少 1 次成功支付的去重付费用户 ÷ 月活学生用户 | 目标 3–5%；退款单独统计 |
| 内容覆盖率 | 已上线章节中，具备知识点映射、≥1 例题、≥N 题、解析齐全的章节占比 | N 见 Q-07 |
| 内容抽检准确率 | 抽检题目中答案/解析/知识点均正确的题目占比 | 建议 ≥98%，致命错误 0 |

> 指标目标来自上游 PRD，属于待验证假设。发布后先建立 4 周基线，再评估是否调整；不得在复盘时改写口径来“达成目标”。

### 8.5 数据留存

- 学习记录、错题、报告：保留至账号注销；注销后删除或匿名化，法定留存除外。
- 内容审核日志、操作日志：按法规与内部制度留存，至少覆盖内容生命周期。
- 埋点与日志：按隐私政策声明的最短必要期限留存；不无限期保留可识别信息。
- 备份数据按备份周期滚动清理，注销用户的备份数据在下一个清理周期处理。

8. 隐私政策/用户协议/未成年人规则初稿完成。

### 9.3 MVP 出口标准（Definition of Done）

MVP 发布必须同时满足：

1. 全部 P0 功能 AC 通过，证据留存；无“待补验收”。
2. S1、S2 缺陷为 0；S3 缺陷有明确处理计划且经产品/技术负责人签字接受。
3. 内容门禁：上线章节 100% 完成教研审定；题目答案/解析抽检准确率 ≥98%，致命错误 0（建议值）。
4. 性能：判分 P95 ≤1 秒、首屏/接口指标达标；压测通过。
5. 兼容：iOS/Android/微信/桌面矩阵通过；375 宽竖屏全流程通过。
6. 安全：无高危/严重漏洞；越权、验证码、上传、日志脱敏测试通过。
7. 合规：协议/隐私/未成年人规则上线；注销流程可用；备案/资质完成或法务书面确认（D-04）。
8. 数据：核心埋点与服务端抽样核对误差 ≤1%（建议值）；北极星等指标可查。
9. 运营：客服入口、工单、内容纠错、紧急下线流程就绪。
10. 发布：灰度与回滚方案、监控告警、值班表就绪。

### 9.5 缺陷分级

| 级别 | 定义 | 发布处理 |
|---|---|---|
| S1 阻断 | 无法完成核心流程、数据丢失/错误、隐私泄露、支付扣款错误、内容严重错误 | 必须修复，禁止发布 |

### 9.6 灰度与回滚

- 首发城市内按 5% → 25% → 100% 灰度，每档观察至少 48 小时（建议值）。
- 回滚触发（建议值）：S1 缺陷、支付/订单异常、判分错误率显著高于基线、数据丢失、隐私事件、核心接口错误率 >2 倍基线。
- 必须具备：功能开关、内容紧急下线、支付入口关闭、版本回滚、公告模板。
- 回滚后 24 小时内完成原因复盘与用户影响评估。

### 9.7 验收记录要求

- 每个 AC 的记录包含：AC 编号、测试环境/设备、执行人、时间、结果、证据链接。
- 内容验收按章节抽检，记录抽检比例、错误类型、修正记录。
- 法务审阅需有版本号与签字/邮件确认。
- 未执行的 AC 必须标注“未执行”，不得写“通过”。
